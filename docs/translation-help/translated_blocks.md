<<<ja|vimshottari-dasha-guide|b8>>>
27のナクシャトラのそれぞれには支配星が割り当てられており、九つの惑星の支配星は27のナクシャトラ全体で同じ固定されたヴィムショッタリーの順序を繰り返します（九つの三回の完全なサイクル）。誕生時に月がどのナクシャトラに位置していたかが、あなたがどの惑星のマハーダシャーの下に生まれたのかをシステムに伝えます。そして、そのナクシャトラ内での月の正確な度数が、あなたが生まれる前にその最初のマハーダシャーがどれだけすでに「経過」していたか、対してどれだけ残っているかを決定します。これもまた、正確な出生時間が不可欠である理由です。月の位置が別のナクシャトラに移動するほど出生時間をずらすと、ダシャーのタイムライン全体が異なる出発点から再計算されてしまいます。

<<<ja|vimshottari-dasha-guide|b11>>>
例えば、現在土星のマハーダシャー（合計19年）にいる人は、次のマハーダシャーが始まる前に、**土星-土星**のアンタルダシャーから始まり、次に**土星-水星**、次に**土星-ケートゥ**と、同じ九つの惑星の順序で進んでいきます。各アンタルダシャーは、そのマハーダシャーのロードとそれ自身のサブロードの両方の組み合わされた性格を持ちます。土星-木星の期間は、両方とも同じ19年の土星のマハーダシャーの中にありますが、土星-ラーフの期間とは全く異なって読み解かれます。
