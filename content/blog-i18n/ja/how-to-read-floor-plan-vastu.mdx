「キッチンは南東に」「家の中心は開けておく」など、ヴァーストゥのどの助言も、家のどこがどの方角に当たるかを知っていることが前提です。そのために間取り図を読みます。間取り図と定規、コンパスがあれば20分ほどででき、確認するのは1度だけです。

<KeyTakeaway>
ヴァーストゥの原則に沿って間取り図を読むには、<strong>真北に合わせて向きを確認し</strong>、<strong>中心を見つけ</strong>、<strong>3 × 3のマス目</strong>を重ね、<strong>各区画に何があるかを書き出し</strong>ます。そのうえで伝統的な指針と照らし合わせ、変更しにくい要素（玄関、キッチン、トイレ、中心）と、配置を変えるだけでよいものを分けて考えましょう。
</KeyTakeaway>

## 必要なもの

- 縮尺の正しい**間取り図**。建築士が作成した図面が理想ですが、最初の確認には施工会社のパンフレットでも構いません。方眼紙に丁寧に描いた手書きの図も使えます。
- **方位磁針**、または補正済みのスマートフォンのコンパス。
- 鉛筆と定規、または図を描ける道具。

## ステップ1: 間取り図を北に合わせる

家の中心で、金属や電子機器から離れてコンパスで方角を測り、間取り図に北を書き込みます。図面の北を示す矢印や衛星地図とも照らし合わせてください。次に、**北が上になるように間取り図を書き直すか、回転させます**。詳しくは[ヴァーストゥにおける方角](/blog/vastu-directions-explained)のガイドをご覧ください。

## ステップ2：中心を見つける

中心、つまり**ブラフマスタン**が、ほかのすべての基準になります。

- **長方形の間取り図:** 2本の対角線を引きます。交点が中心です。
- **L字型や不整形の間取り図:** 間取り全体を囲む最小の長方形の中心、または、より正確には間取りの面積重心を使います。欠けた角や張り出しの扱いは実践者によって異なるため、不整形の間取りの中心は厳密な1点ではなく、ある程度の広がりを持つ範囲として考えましょう。
- **バルコニー:** 間取りに含めるかどうかを決めます（屋根付きのものは含め、屋根のないものは除く実践者が多いです）。決めた基準を一貫して適用しましょう。

## ステップ 3: グリッドを引く

間取り図を**縦に3等分、横に3等分**します。これで9つの区域ができます。

<FloorPlan grid caption="北を上にした図面上に重ねた 3 × 3 のグリッド。外側の八つのマスは方位のゾーンを表し、中央のマスはブラフマスタハンです。" />

| 北西 | 北 | 北東 |
| --- | --- | --- |
| **西** | **中央** | **東** |
| **南西** | **南** | **南東** |

一部の現代の実践者は、中心から 22.5°ごとに線を引く、より細かい **16 ゾーン**手法を用います。これは特に大きな住宅で詳細な情報を提供しますが、伝統的なガイダンスは主に八方位と中央に基づいているため、3 × 3 のグリッドが正しい出発点です。

### 家が斜めに建っている場合

壁が北に対して約45°傾いている場合、グリッドは綺麗に収まりません。壁に合わせてグリッドを合わせるのではなく、中心から放射状に線を引いて八方向を描いてください。家の**コーナー**が北、東、南、西を向いていることに気づくはずです。これは自然なことです。ゾーンをそのままの位置のままで読み取ってください。

## ステップ 4: 各ゾーンにあるものを書き出す

簡単な表を作りましょう。各ゾーンにある主な部屋や設備を記し、玄関、コンロ、トイレ、階段（あれば）がどこにあるかも書き込みます。

| 方角・場所 | そこにあるもの（例） |
| --- | --- |
| 北東 | プージャのスペース、窓 |
| 北 | リビング |
| 北西 | ゲスト用寝室 |
| 東 | 玄関 |
| 中央 | 通路 |
| 西 | 浴室 |
| 南東 | キッチン |
| 南 | ダイニング |
| 南西 | 主寝室 |

## ステップ5: 伝統的な指針と照らし合わせる

| 方位 | 伝統的に適している用途 | 一般的に避ける用途 |
| --- | --- | --- |
| **北東** | プージャ、開放的な空間、窓、水回り | トイレ、キッチン、重い物の収納 |
| **東** | 玄関、リビング、勉強部屋 | 重い物の収納 |
| **南東** | キッチン、電気設備 | 主寝室、貯水タンク |
| **南** | 寝室、収納 | 玄関（一般的な助言では） |
| **南西** | 主寝室、重い家具 | 玄関、トイレ、開放的な空間 |
| **西** | ダイニング、子ども部屋 | 特になし |
| **北西** | 客間、浴室やトイレ、収納 | 特になし |
| **北** | 玄関、リビング、開放的な空間 | 重い物の収納 |
| **中央** | 開放的な空間 | トイレ、階段、厚い壁 |

各部屋のガイドでは、さらに詳しく紹介しています。[玄関](/blog/main-entrance-vastu)、[キッチン](/blog/kitchen-vastu)、[寝室](/blog/bedroom-vastu)、[リビング](/blog/living-room-vastu)、[プージャールーム](/blog/pooja-room-vastu)をご覧ください。

## ステップ 6: 大切なこととそうでないことを分ける

ここは多くの人が飛ばしてしまうステップですが、ヴァーストゥを無理なく取り入れるために大切です。気づいたことを、それぞれ次の2つのグループのどちらかに分けましょう。

**変えるのが難しいこと**（購入や建築の前に考慮したいこと）:

- 玄関の方角と位置
- キッチンの位置とガス配管
- トイレの位置
- 家の中央が開けているか

**変えやすいもの**（入居後に調整できます）:

- どの寝室を主寝室として使うか
- ベッド、ソファ、クローゼットの位置
- 祭壇を置く場所
- 北東と中央に何を収納するか

問題が2つ目のグループにしかない家なら、ほとんどの専門家の基準では良い状態です。

## 一戸建てと敷地の場合

独立した敷地に建つ家の間取り図を読む場合、専門家は敷地自体も確認します。伝統的には、北側と東側により広い空き地があるか、南側と西側の地盤が高く、重い構造物があるか、そして敷地がどのような形をしているかを見ます。上記の方法は、建物自体にもそのまま当てはまります。
