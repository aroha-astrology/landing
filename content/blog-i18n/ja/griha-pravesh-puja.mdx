新居への引っ越しは、家族にとって大きな節目の1つです。ヒンドゥー教の伝統では、文字どおり「家に入る」を意味する**グリハ・プラヴェーシュ**という儀式で、この節目を祝います。新しい家やマンションに住み始める前、または住み始める際に行い、家とそこに暮らす人々への祝福を願います。

<KeyTakeaway>
グリハ・プラヴェーシュは、パンチャンガをもとに選んだ<strong>縁起のよい時刻（ムフールタ）</strong>に行います。一般的な儀式には、<strong>ガネーシャ・プージャー</strong>、<strong>カラシュ・スターパナ</strong>、家族が<strong>儀式として初めて家に入ること</strong>、<strong>ヴァーストゥ・プージャー</strong>、多くの場合は<strong>ハヴァン</strong>も含まれます。また、新しい台所で<strong>牛乳を吹きこぼれるまで沸かす</strong>習慣もあります。細かな進め方は地域や家庭によって異なります。
</KeyTakeaway>

## グリハ・プラヴェーシュの3つの種類

伝統的な文献や祭司は、一般に次の3つのケースを区別します。

| 種類 | 該当する場合 |
| --- | --- |
| **アプールヴァ** | 新築または購入した家に初めて入るとき |
| **サプールヴァ** | 海外での長期滞在など、長く留守にした家に戻るとき |
| **ドヴァンドヴァ** | 大規模な改修や修繕、または災害の後に家に入り直すとき |

アプールヴァのグリハ・プラヴェーシュでは通常、最も充実した儀式を行います。ほかの2つは、より簡素に行うことが多いです。

## ムフールタの選び方

多くの家庭では、司祭や占星術師に[パンチャンガ](/blog/what-is-panchang)を見てもらって日取りを決めます。慣習はさまざまですが、一般的に考慮されるのは次のような点です。

- **月。** マーガ月、パールグナ月、ヴァイシャーカ月、ジェーシュタ月は、吉月としてよく挙げられます。アディク・マース（閏月）とカルマース（太陽が射手座または魚座にある時期）は一般に避けられ、チャトゥルマースの期間を避ける家庭もあります。
- **ティティ。** 「リクタ」と呼ばれるティティ（第4、第9、第14）とアマーヴァスヤーを避ける人が多くいます。
- **ナクシャトラ。** ローヒニー、ムリガシラー、チトラー、アヌラーダー、ウッタラ・パールグニー、ウッタラ・アーシャーダー、ウッタラ・バードラパダー、レーヴァティーなどのナクシャトラは、吉とされることがよくあります。
- **時間帯。** 選ぶ時間帯はラーフ・カールを避け、僧侶がラグナを計算する場合は、吉とされるラグナに合わせます。

これらは伝統に基づく目安と考えてください。ご自身の地域の祭司は少し異なる作法を用いることもあります。また、多くの家族は、理想の日取りと、家の引き渡し日や仕事の予定といった現実的な事情との折り合いをつけています。

## 準備のスケジュール

| いつ | すること |
| --- | --- |
| **3-4週間前** | ムフルタの日時を決め、パンディットを予約し、儀式の規模と招待客のリストを決める |
| **2週間前** | 儀式の供物や道具をパンディットが持参するのか、自分たちで用意するのかを確認し、必要なもののリストをもらう |
| **1週間前** | 修理と念入りな掃除を済ませ、水道、ガス、電気が使えることを確認する |
| **2-3日前** | 儀式の供物や道具、花、食べ物を購入または手配済みか確認し、座席とハヴァンを安全に行える場所を用意する |
| **前日** | トーランを飾り、カラシュに使うものを準備し、牛乳用の新しい器を用意する |
| **当日** | 玄関にランゴリを描き、家族はムフルタの前に準備を済ませ、携帯電話をマナーモードにする |

## 用意するもの

必要なものの正確なリストは、伝統に合わせてパンディットが案内してくれます。一般的なグリハ・プラヴェーシュでは、カラシュ、ココナッツ、マンゴーの葉、トーラン、花と花輪、クムクム、ターメリック、米、キンマの葉とビンロウの実、ギー、灯明、樟脳、お香、果物とお菓子、新しい器と牛乳を用意します。ハヴァンを行う場合は、ハヴァン・クンド、薪、ハヴァン用の供物も必要です。[プージャの供物ガイド](/blog/puja-samagri-list)では、これらに伝統的にどのような意味があるかを説明しています。

## マンションで行う場合

マンションでのグリハ・プラヴェーシュも、少し計画を立てればスムーズに進められます:

- **管理組合に確認しましょう。** ハヴァンの煙やエレベーターの利用、参列者用の駐車場について確認しておきましょう。
- **煙感知器にも気を配りましょう。** 小さな住戸でハヴァンを行うと警報が鳴ることがあります。小さめのハヴァン・クンドを使う、十分に換気する、バルコニーで行うといった方法が役立ちます。
- **火の安全対策も忘れずに:** ハヴァン・クンドの下に金属製のトレーを敷き、近くに水を入れたバケツを置きましょう。真上には燃えやすいものを置かないでください。
- **近隣の方に知らせておきましょう。** 心遣いになりますし、マントラの声や鈴の音が周囲に届くこともあります。

引っ越す前に確認しておきたいことは、[マンションやアパートのヴァーストゥ](/blog/vastu-for-flats-apartments)をご覧ください。

## 家族がこの儀式を行う理由

多くの家族にとって、グリハ・プラヴェーシュは、家に祝福と守りを願う信仰の行為です。また、家族が集まり、食事を分かち合い、建物を暮らしの場にしていくことで、**新たな始まりを祝う**意味もあります。どちらも大切な理由です。儀式をどのくらい丁寧に行うか、ムフールタにどの程度厳密に従うかは、家族で決めることです。

まもなく登場する Aroha Puja は、このような儀式のために開発中です。グリハ・プラヴェーシュのパンディットを予約し、儀式に必要なサマグリをすべて持参してもらうか、ご家族で用意するかを選べます。予約受付はまだ始まっていません。
