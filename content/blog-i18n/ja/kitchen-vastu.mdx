キッチンのヴァーストゥについて1つだけ覚えるなら、これです。キッチンは**火**の場所であり、ヴァーストゥでは火に**南東**の方角を割り当てます。キッチンに関するほかの助言も、ほぼすべてここから、そして火と水を離しておくというもう1つの考え方から生まれています。

<KeyTakeaway>
伝統的なヴァーストゥでは、<strong>キッチンは南東</strong>に配置します（代わりに北西も可）。<strong>コンロはキッチンの南東</strong>に置き、料理をする人が<strong>東を向く</strong>ようにします。<strong>シンクは北東寄り</strong>に置き、コンロとの間に距離を取ります。重い収納は南側と西側の壁に配置します。
</KeyTakeaway>

## キッチンを配置する方角

ヴァーストゥの5元素の配置では、南東は火を司るアグニの領域です。そのため、伝統的に台所を設ける場所とされています。

<VastuCompass highlight={['SE']} caption="南東（アグネーヤ）は火の領域で、伝統的に台所を設ける場所です。" />

| キッチンの方角 | 伝統的な見方 |
| --- | --- |
| **南東** | 理想的 |
| **北西** | 代替として最も広く認められている |
| **東または南** | 一部の指針では許容される |
| **北東** | 避けるべきとされる。水の領域であり、明るく開放的に保つ場所 |
| **南西** | 一般的な指針では避けるべきとされる |
| **中央** | 避けるべきとされる。ブラフマスタンは開放的に保つべき場所 |

## キッチンの中

ヴァーストゥでは、部屋の中にも同じ方位の考え方を当てはめます。キッチンを、それ自体に8つの方位がある小さな間取りとして考えてみましょう。

<FloorPlan highlight={['kitchen']} caption="キッチンを南東に配置した間取りの例です。その中では、コンロをキッチン自体の南東部分に置きます。" />

| 項目 | 伝統的な配置 |
| --- | --- |
| **コンロ / 調理台** | キッチンの南東側。調理する人が東を向くように配置します |
| **シンクと浄水器** | キッチンの北東側 |
| **冷蔵庫** | 南西、南、または西。北東は避けます |
| **電子レンジ、オーブン、ミキサー** | 南東または南（火や電気に関わる場所です） |
| **重い収納棚、穀物、調理器具** | 南側と西側の壁沿い |
| **窓や換気扇** | 東側。朝の光を取り入れ、煙を外に逃がします |
| **食卓**（キッチンに置く場合） | 西側 |

### 火と水は離して配置する

ヴァーストゥでは、コンロ（火）とシンク（水）は相反する要素です。伝統的には、2つを**離して**配置することが勧められています。同じ調理台に並べたり、キッチンを挟んで真正面に向かい合わせたりしないようにします。L字型の調理台なら、片側にコンロ、もう片側にシンクを置けば、たいていこの問題は解決します。

### どちらを向いて調理するか

料理をするときは**東**を向く、というのが最も一般的な教えで、次に勧められるのは北です。実際には、コンロを東側の壁沿いか南東の隅に置くことになります。東を向いて料理をすれば朝の光も浴びられます。伝統と実用性が一致する点の1つです。

## キッチン、ドア、浴室

- **正面玄関と真正面に向き合わない配置**。一般的な指針では、玄関から入って最初にコンロが目に入らないようにします。
- **トイレと壁を共有しない配置**。複数階建ての家では、避けられるならトイレの真上や真下にも置かないようにします。
- **家の通り道にならない配置**。ほかの部屋へ行くために必ずキッチンを通らなければならない間取りは、避けたほうがよいとされています。

## 色とお手入れ

キッチンには伝統的に暖色系が好まれます。オレンジ、黄色、テラコッタ、温かみのあるクリーム色などです。黒や非常に暗い色の仕上げは、一般に避けたほうがよいとされています。多くの専門家は、色と同じくらい**清潔さ**を重視します。コンロをきれいに保ち、水漏れする蛇口や古くなった食べ物を放置せず、調理台に物を散らかさないことが大切です。

## 伝統と実用性が重なるところ

キッチンに関する決まりには、少し神秘的に聞こえても、実際には理にかなった効果があるものがあります：

- **東向きの窓**があると、朝日が入り、風も通りやすくなります。
- **コンロとシンクを離す**と、火の近くへの水はねが減り、2人で作業する場所も確保できます。
- **キッチンを家の主要な動線から外す**と、安全面でもよいでしょう。

だからといって、火と繁栄に関するヴァーストゥの主張が証明されるわけではありません。ただ、これらの工夫を取り入れても、たいていは費用がかかりません。

## システムキッチンの場合

マンションのキッチンでは、調理台やガス配管、水道管の位置が決まっていることがほとんどです。それでも、通常は次のことができます。

キッチンが北東や、ほかの避けるべきとされる方位にある場合、一般的には部屋の中の配置を整え、建物の構造はそのままにしておくことが勧められます。伝統的な文献にも、慌てる必要があるとは書かれていません。ガス管の移設は、ヴァーストゥのためではなく、安全上の理由がある場合に限り、必ず有資格者に依頼してください。
