すべての vastu 聖典は土地から始まります。家が建つ土地は伝統において **ヴァストゥ・プルーシャ** と、その上に休むとされる神々によって支配されています。**ヴァストゥ・シャンティ**（「住まいの平和」）とは、これらを尊重する儀式であり、家とその住人たちが調和するように祈るプージャです。通常、ホーモンを伴います。

<KeyTakeaway>
バストゥ・シャンティは、バストゥ・プルシャおよびその土地の神々に捧げる<strong>プージャおよびハヴァン</strong>です。ご家族は<strong>新しいお家へ引っ越しをした時</strong>（グリハ・プラヴェーシュの一環として行われることも）、<strong>大規模な改装後</strong>、あるいは中古物件を引き継いだ際に行うことが一般的です。これは建築に物理的な修正を加えるものではなく、信仰に基づく儀式です。
</KeyTakeaway>

## それが行われる背景

vastu 大蔵経の根本にある物語では、神々によって大地に押し付けられた巨大な存在が、彼が体の各部分に神々を宿すようになった「 vastu プルシャ」になります。各場所の部分は神々と関連付けられました。 vastu プランの基盤となるグリッドである ** vastu プルシャ マンダラ** は、これらの神々を計画にマッピングします。[what vastu shastra is](/blog/what-is-vastu-shastra) についての当社のガイドは、これについて詳しく説明しています。

この伝統において、土地の造成・掘削・改変を行う際は、神々に対する敬意と供え物が必要とされます。ヴァストゥ・シャンティが、その供え物です。

## 家族がこれを行う時期

| 機会 | 伝統的な理由 |
| --- | --- |
| **新家に移る前** | その場所に住む前に祝福するため。しばしば [グリーハ・プラヴェシュ](/blog/griha-pravesh-puja) と併せて行われます |
| **大規模なリフォームや再建の後** | 土地が荒らされたため |
| **古く、長期間空き家だった家への入居** | 歴史ある家で新たにスタートを切るため |
| **家がヴァースツの理想から外れているとき** | 間取りを現実的に変えられない場合の伝統的な祈祷 |
| **定期的に** | ある家系では一定の間隔で繰り返したり、節目の記念日に執り行ったりします |

## ヴァストゥ・シャンティとグリーハ・プラヴェーシュの比較

| | ヴァストゥ・シャンティ | グリハ・プラヴェシュ |
| --- | --- | --- |
| 焦点 | 土地とその神々 | 家族の自宅への初入居 |
| 中心となる儀式 | ヴァストゥ・マンダラ・プージャ、ヴァストゥ・ホーマ | ガネーシャ・プージャ、カラシュ、祝祭的な入居、牛乳を沸かす |
| 時期 | 新居、改装、古民家 | 引越 |
| 一緒に執り行われる？ | グリハ・プラヴェシュの一環として頻繁に | ヴァストゥ・プージャまたはフル・ヴァストゥ・シャンティを伴うことが多い |

## できることとできないこと

ヴァストゥ・シャンティは時に「 remedies（解決策）」として売り出されます。

伝統においてヴァストゥ・シャンティは土地を鎮め、多くの家族が暮らす前に家を祝福する意味を見出しています。それが**何であるか**は建物の改修ではありません。トイレを北東から動かすわけでも、暗い部屋に光をもたらすわけでもありません。実務的な問題は実務的に解決するのが最も良く、どのような対策が効果的かは[一般的なヴァストゥの間違い](/blog/common-vastu-mistakes)をご覧ください。そして、これを行わないと家族に災いが降りかかるといった約束で儀式を販売してはいけません。

## 準備

- **パンドィットに予約**し、伝統に従う手順、所要時間、ハヴァンが含まれるかを確認してください。
- **サマグリ（供物品）の手配者を問い合わせてください。** ヴァストゥ・シャнтиには単なるプージャー以上のものが必要で、通常はカラシャ、ココナッツ、マンゴーの葉、米、マンダラ用の色粉、花、ギー、ハヴァン用の木材とサマグリ、ナヴァダーニヤ（九穀）、果物、お菓子などが含まれます。詳細は[samagriガイド](/blog/puja-samagri-list)をご覧ください。
- **空間を確保する**曼荼羅とハヴァン・クンドを置くのに十分なスペースを、パンドィットのアドバイスに従い、理想的には家の中心部か北東に用意してください。
- **マンションの場合:** 換気や小型のハヴァンを想定して煙への備えをし、煙探知機を確認し、近くに水を置いておいてください。
