月は約27⅓日かけて黄道全体を一周します。ヴェーダ占星術はこの軌道を**27のナクシャトラ**、すなわち月の宿に分割しており、それぞれが空の**13°20′**を占めます。これはおおよそ月の旅の一日に一宿にあたる計算です。このページでは、 astrologers が最もよく使う詳細情報とともに、これら27のナクシャトラを一覧で紹介します。その後、各項目が何を意味するかを解説します。

初めて知る方は、まず[ナクシャトラとは何か](/blog/what-is-a-nakshatra)から読んでみてください。このページは、あとで見返せる資料として役立ちます。

<KeyTakeaway>
27のナクシャトラは、<strong>アシュヴィニー</strong>（牡羊座0度）から<strong>レヴァティ</strong>（魚座の終わり）まで決まった順番で並んでいます。それぞれにヴィムショッタリーのシーケンスからの支配星、主神、シンボル、そして3°20′の四つのパダがあります。あなたが生まれた時に月が位置していたナクシャトラが、あなたの<strong>ジャンマ・ナクシャトラ</strong>です。
</KeyTakeaway>

## 各列の見方

### 範囲

この範囲は、占星術が使用する**恒星黄道**（シデリアル・ゾディアック）で測定されます。西洋（太陽黄道）のチャートと比較すると、位置はおよそ 24°先になります。詳しくは[Rashi vs Sun sign](/blog/rashi-vs-sun-sign)をご覧ください。九つの nakshatra は一つのサインから次のサインへまたがっており、例えばクリッティカの場合、牡羊座で始まり牡牛座で終わるのもそのためです。サインと nakshatra がどのように組み合わさるかは、[Rashi vs Nakshatra](/blog/rashi-vs-nakshatra)をご覧ください。

### 支配星

この並びに注目してください。**ケートゥ、金星、太陽、月、火星、ラーフ、木星、土星、水星**が3回繰り返されています。これは[ヴィムショッタリ・ダシャー](/blog/vimshottari-dasha-guide)の順序です。生まれたときに月が位置していたナクシャトラの支配星が、人生最初のダシャーを司ります。そのナクシャトラを月がどこまで進んでいたかによって、その期間の残りの長さが決まります。

### 神格

各ナクシャトラには、ヴェーダの神々の中から守護神が定められています。たとえば、クリッティカーには火の神アグニ、アールドラーにはルドラ、シュラヴァナにはヴィシュヌが対応します。占星術師は守護神を手がかりに、そのナクシャトラに伝統的に結びつけられてきた性質を説明します。たとえば、嵐の神ルドラが司るアールドラーは、激動と再生に結びつけられています。こうした説明は予言ではなく、伝統に基づく象徴的な表現として受け止めてください。

### 象徴

これらのシンボルは古くから伝わる、覚えるための図像で、星の集まりの形と結びついていることがよくあります。対になっているものもあり、2つのパールグニーはベッドの前脚と後脚、2つのバードラパダーは簡易ベッドの前部と後部を表します。

## 3つのガナ

ナクシャトラは気質を表す**ガナ**によっても分類されます。この分類は主に[グナ・ミラン](/blog/guna-milan-ashtakoota-compatibility)で相性を判断する際に使われます。

| ガナ | ナクシャトラ |
| --- | --- |
| **デーヴァ** (神聖) | アシュヴィニー、ムリガシラー、プナルヴァス、プシュヤ、ハスタ、スヴァーティー、アヌラーダー、シュラヴァナ、レーヴァティー |
| **マヌシャ** (人間) | バラニー、ローヒニー、アールドラー、プールヴァ・パールグニー、ウッタラ・パールグニー、プールヴァ・アーシャーダー、ウッタラ・アーシャーダー、プールヴァ・バードラパダー、ウッタラ・バードラパダー |
| **ラクシャサ** (激しい) | クリッティカー、アーシュレーシャー、マガー、チトラー、ヴィシャーカー、ジェーシュター、ムーラ、ダニシュター、シャタビシャー |

「ラクシャサ」は怖く聞こえるかもしれませんが、伝統的には気性が強く自立心のある性質を表す言葉で、その人や出生図が悪いという意味ではありません。

## 名前の由来となった星々

ナクシャトラは実在する星の集まりにちなんで名付けられており、夜空で見つけやすいものもいくつかあります：

| ナクシャトラ | 一般に対応づけられる星 |
| --- | --- |
| クリッティカー | プレアデス星団 |
| ローヒニー | アルデバラン |
| アールドラー | ベテルギウス |
| プナルヴァス | カストルとポルックス |
| マガー | レグルス |
| チトラー | スピカ |
| スヴァーティー | アークトゥルス |
| ジェーシュター | アンタレス |
| シュラヴァナ | アルタイル |

黄道は13°20′ずつの等しい区間に分けられているため、ナクシャトラが占める範囲と、その名前の由来となった星の位置は必ずしも正確には重なりません。占星術で用いるのは、この区間です。

## パダと名前に使う音節

各ナクシャトラは3°20′の四つの**パダ**に分かれます。それぞれのパダには、名前に使われる伝統的な最初の音節があります。例えば、月がアシュヴィニーの四つのパダのいずれかにある子供には、伝統的にチュ、チェ、チョ、またはラの音から始まる名前が付けられます。この習慣に従う家族は、通常、ナクシャトラだけでなくパダも尋ねます。

## 自分のナクシャトラを調べる方法

生年月日、出生時刻、出生地が必要です。月は約1日で1つのナクシャトラを移動するためです。Arohaの[月星座計算ツール](/moon-sign)では、月のラーシとナクシャトラが分かり、Aroha Astrologyアプリでは、そのナクシャトラから始まるダシャーの流れを確認できます。
