リビングは、家の中で最も人が集まる部屋です。来客を迎え、家族が集まり、多くの集合住宅では玄関から入って最初に足を踏み入れる部屋でもあります。ヴァーストゥでも、リビングをそれにふさわしい場所として考えます。基本となるのは、**北と東を開放的に保つこと**、そして**南と西に重みを持たせること**です。

<KeyTakeaway>
ヴァーストゥでは伝統的に、リビングを<strong>北、東、または北東</strong>に配置します。大きなソファなどは<strong>南と西の壁際</strong>に置き、座る人が北か東を向くようにします。<strong>テレビは南東</strong>に置き、<strong>北東の角には重いものを置かず</strong>、部屋の中央は空けておきます。
</KeyTakeaway>

## リビングを配置する場所

| リビングの方角 | 伝統的な考え方 |
| --- | --- |
| **北** | 好まれる。開放感と繁栄に結びつけられる |
| **東** | 好まれる。朝の光が入る |
| **北東** | 明るく、物が散らかっていなければ好まれる |
| **北西** | 一般的で問題ない。人の行き来や来客に結びつけられる |
| **南西** | あまり好まれない。伝統的には主寝室に充てられる |

## 家具：重いものは南西に、軽いものは北東に

家全体に当てはまる原則は、部屋の中にも当てはまります。リビングを、8つの方位を持つ小さな間取りとして考えてみましょう。

| 項目 | 伝統的な配置 |
| --- | --- |
| **ソファと重い椅子** | 南または西の壁沿い |
| **座る向き** | 座る人が北または東を向く |
| **テレビ、スピーカー、電子機器** | 部屋の南東側 |
| **重い戸棚や本棚** | 南または西の壁沿い |
| **植物、軽い装飾品** | 北または東側。特に北東側は物を少なくする |
| **部屋の中央** | 空けておき、テーブルを置くなら低いものだけにする |
| **階段**（メゾネットの場合） | 南、西、または南西に配置し、時計回りに上る |

### 北東の角

多くのヴァーストゥの実践者が特に重視する場所です。清潔で明るく、物を置きすぎないようにしましょう。植物や窓、明るい色の壁が似合います。一般的な助言では、北または北東に小さな水景や水槽を置くことも勧められます。これは、ヴァーストゥで北東を水と結びつける考え方に沿っています。ただし、選択肢の1つであり、必須ではありません。

### 中央

部屋の中央は、家の中心と同じように、伝統的には空けておきます。重いコーヒーテーブルや柱を中央に置いたり、家具を集めたりするのは、その考え方に反します。ラグや低いテーブルなら問題ありません。

## 光、色、雰囲気

- **北側と東側の窓**は、やわらかな日光が入るため好まれます。
- **明るく暖かみのある色**：白、クリーム色、淡い黄色、薄い緑色が一般的にすすめられます。
- **照明**：薄暗い部屋よりも、明るく十分に照らされたリビングルームが好まれます。
- **絵やアート**：一般的なヴァストゥの考え方では、争いや悲しみを描いたものより、穏やかで前向きな印象のものが好まれます。これは伝統だけでなく、部屋の雰囲気にも関わることです。

## リビングとダイニングが一体になっている場合

多くの集合住宅では、リビングとダイニングが細長い1つの空間になっています。そこでヴァーストゥを実用的に取り入れる方法は次のとおりです。

- **座るスペースは北側または東側**の半分に、入り口の近くに配置します。
- **ダイニングテーブルは西側**の半分に置きます。西は伝統的に食事に適した方角です。
- 家具を避けながら歩かずに入れるよう、**入り口から部屋の奥へ続く通路を空けて**おきます。

## 暮らしに合わせて無理なく取り入れる
