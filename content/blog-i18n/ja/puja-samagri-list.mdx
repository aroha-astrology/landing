*サマグリ*とは、単に材料、つまりプージャの前に用意するものを意味します。毎日のプージャに必要なのはほんの一握りですが、グリハ・プラヴェーシュやハヴァンでは数十種類が必要になります。それぞれの品には伝統的な意味があり、それを知ることで、この儀式は単なる買い物リスト以上のものになります。

習慣は地域、コミュニティ、神格によって異なるため、これは一般的なガイドとして参考にし、異なる点についてはご家族やパンディットのリストに従ってください。

<KeyTakeaway>
基本のセットは、<strong>ディヤ</strong>、<strong>お香</strong>、<strong>水</strong>、<strong>クンクムとハルディ</strong>、<strong>アクシャタ</strong>（粒のままの米）、<strong>花</strong>、<strong>食べ物のお供え</strong>を<strong>ターリー</strong>に載せたものです。規模の大きい儀式では、<strong>カラシュ</strong>、<strong>ココナッツ</strong>、<strong>マンゴーの葉</strong>、<strong>キンマの葉とビンロウの実</strong>、<strong>マウリ</strong>の糸、<strong>パンチャームリタ</strong>を加え、ハヴァンを行う場合は<strong>ハヴァン用の供物</strong>も用意します。
</KeyTakeaway>

## 日々のプージャに欠かせないもの

| 品目 | どのようなものか | 伝統的な意味 |
| --- | --- | --- |
| **ディヤ** | ギーまたはオイルを入れた、綿の芯付きの土製または真鍮製のランプ | 暗闇を照らす光。炎はプージャーの証人とされる |
| **アガルバッティ / ドゥープ** | お香のスティックまたはコーン | 神への供物として捧げる香り。5つの基本的な供物の1つ |
| **水（ジャル）** | 小さな器（*ロタ*）に入れた清らかな水 | 浄化。ウパチャーラで洗浄や口をすすぐために捧げる |
| **クムクム / ローリー** | 赤い粉 | 吉祥。神に塗り、ティラクとしても用いる |
| **ハルディ** | ターメリック | 純粋さと吉祥 |
| **チャンダン** | サンダルウッドのペースト | 清涼感のある香り高い供物（*ガンダ*） |
| **アクシャタ** | クムクムを混ぜることが多い、丸ごとで割れていない米 | 完全性と繁栄 |
| **花** | 生花と花輪 | 美しさと献身。特定の花は特定の神々と結び付けられている |
| **ナイヴェーディヤ** | 果物、菓子、牛乳または調理した料理 | 神に捧げる食べ物。その後、プラサードとして分け合う |
| **鐘（ガンティ）** | 手で鳴らす小さな鐘 | 礼拝の開始時やアールティの最中に鳴らす |
| **ターリー** | 真鍮またはスチール製のことが多い皿 | 供物を載せる。アールティに使う |
| **樟脳（カルプール）** | 白い樟脳のタブレット | アールティの際に燃やす。燃えた後に何も残らないため、エゴが溶けてなくなる象徴と解釈されることが多い |

## 大規模なプージャに使う品々

| 品目 | 伝統的な意味 |
| --- | --- |
| **カラシュ** | 満ち足りた状態と神聖な存在を表す水 pot。多くの儀式の中心となる |
| **マンゴーの葉** | カラシュの口や玄関のトーランに置かれ、 शुभなもの、新たな始まりと結び付けられている |
| **ココナッツ（シュリファル）** | 清らかな供物。カラシュの上に置いたり、供物として割ったりする |
| **ベテルの葉と実（パーン、スパリ）** | *タンブーラ*として捧げ、敬意を表す。スパリをガネーシャとして礼拝することもある |
| **マウリ / カラワ** | 赤と黄色の聖なる糸。手首やカラシュの周りに結び、守護と誓いの印とする |
| **パンチャームリタ** | 牛乳、カード、ギー、はちみつ、砂糖を混ぜたもの。神像を清める沐浴に使い、プラサードとして分けられる |
| **ガンガージャル** | 多くの家庭で浄化に使われる、ガンジス川の水 |
| **ジャネウ** | 一部のプージャで神に捧げる聖なる糸 |
| **布（ヴァストラ）** | 通常は赤または黄色の新しい布。神に捧げたり、祭壇を覆ったりする |
| **トゥルシーの葉** | ヴィシュヌとクリシュナに捧げる。伝統的にガネーシャには捧げない |
| **ベル（ビルヴァ）の葉** | シヴァに捧げる |
| **ドゥルヴァ草** | ガネーシャに捧げる |
| **ダクシナ** | 伝統的に僧侶に渡す金銭の供物 |

## ホーマのために

ホーマ（火の儀式）には、専用の品々も加わります。

- **ホーマ・クンダ**: 火を焚くための銅または鉄製の容器で、段状になっていることが多い
- **サミダー**: 乾燥させた薪で、マンゴーの木が一般的
- **ホーマ・サーマグリー**: ハーブ、穀物、砂糖、樹脂を調合したもの
- **ギー**: スプーンで火に捧げる
- **ナヴァダーニヤ**: 9つの惑星に関連する9種類の穀物で、一部のプージャで使われる

## 購入と保管

- **生鮮品は新鮮なものを購入する**: 花、果物、ビンロウジの葉は、行う日の近くに用意します。
- **粉類に人工着色料が使われていないか確認する**: 多くの家庭では、天然のクムクムとハルディを好みます。
- **耐久性のある品はまとめて保管する**: プージャーのスペースで、清潔で乾いた状態にしておきます。詳しくは[プージャー室のVastu](/blog/pooja-room-vastu)をご覧ください。
- **何を誰が用意するか確認する。** 大きな儀式では、パンディットがサーマグリーを持参するのか、それとも自分で用意するのかを確認します。こちらの[自宅でプージャーを行うためのパンディットの予約](/blog/how-to-book-pandit-for-puja-at-home)ガイドで詳しく説明しています。

## その後

使い終えた花や葉、米は、ゴミ箱に捨てるのではなく、伝統的に敬意をもって扱われます。現在では、多くの家庭が、川や湖の汚染を避けながら習慣の精神を守るため、**それらを堆肥にしたり、庭に埋めたりしています**。ハヴァンの灰は、庭や植木鉢に撒くことがよくあります。

Aroha Pujaは近日公開予定で、予約ごとに、パンディットがすべてのサマグリを持参するか、ご家族がリストをもとに用意するかを選べます。料金は選択内容に応じて変わります。
