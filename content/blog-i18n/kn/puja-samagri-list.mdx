*ಸಾಮಗ್ರಿ* ಎಂದರೆ ಪೂಜೆಗೆ ಮುನ್ನ ಒಟ್ಟುಗೂಡಿಸುವ ವಸ್ತುಗಳು. ನಿತ್ಯ ಪೂಜೆಗೆ ಅವುಗಳಲ್ಲಿ ಕೆಲವೇ ಸಾಕು; ಗೃಹಪ್ರವೇಶ ಅಥವಾ ಹವನಕ್ಕೆ ಹಲವಾರು ವಸ್ತುಗಳು ಬೇಕಾಗುತ್ತವೆ. ಪ್ರತಿಯೊಂದು ವಸ್ತುವಿಗೂ ಸಾಂಪ್ರದಾಯಿಕ ಅರ್ಥವಿದೆ. ಅದನ್ನು ತಿಳಿದಾಗ ಪೂಜೆಯು ಕೇವಲ ಖರೀದಿ ಪಟ್ಟಿಗಿಂತ ಹೆಚ್ಚಿನ ಅರ್ಥ ಪಡೆಯುತ್ತದೆ.

ಆಚರಣೆಗಳು ಪ್ರದೇಶ, ಸಮುದಾಯ ಮತ್ತು ದೇವತೆಗೆ ಅನುಗುಣವಾಗಿ ಬದಲಾಗುತ್ತವೆ. ಆದ್ದರಿಂದ ಇದನ್ನು ಸಾಮಾನ್ಯ ಮಾರ್ಗದರ್ಶಿಯಾಗಿ ಪರಿಗಣಿಸಿ. ನಿಮ್ಮ ಕುಟುಂಬದ ಅಥವಾ ಪಂಡಿತರ ಪಟ್ಟಿಯಲ್ಲಿ ವ್ಯತ್ಯಾಸವಿದ್ದರೆ ಅದನ್ನೇ ಅನುಸರಿಸಿ.

<KeyTakeaway>
ಮೂಲ ಪೂಜಾ ಸಾಮಗ್ರಿಗಳೆಂದರೆ <strong>ದೀಪ</strong>, <strong>ಧೂಪ</strong>, <strong>ನೀರು</strong>, <strong>ಕುಂಕುಮ ಮತ್ತು ಅರಿಶಿನ</strong>, <strong>ಅಕ್ಷತೆ</strong> (ಇಡೀ ಅಕ್ಕಿ), <strong>ಹೂವುಗಳು</strong> ಮತ್ತು <strong>ನೈವೇದ್ಯ</strong>. ಇವುಗಳನ್ನು <strong>ಪೂಜಾ ತಟ್ಟೆಯಲ್ಲಿ</strong> ಇಡಲಾಗುತ್ತದೆ. ದೊಡ್ಡ ಪೂಜೆಗಳಿಗೆ <strong>ಕಲಶ</strong>, <strong>ತೆಂಗಿನಕಾಯಿ</strong>, <strong>ಮಾವಿನ ಎಲೆಗಳು</strong>, <strong>ವೀಳ್ಯದೆಲೆಗಳು ಮತ್ತು ಅಡಿಕೆ</strong>, <strong>ಮೌಲಿ</strong> ದಾರ, <strong>ಪಂಚಾಮೃತ</strong> ಮತ್ತು ಹವನಕ್ಕೆ <strong>ಹವನ ಸಾಮಗ್ರಿ</strong> ಕೂಡ ಬೇಕಾಗುತ್ತದೆ.
</KeyTakeaway>

| **ಮಾವಿನ ಎಲೆಗಳು** | ಕಳಶದ ಬಾಯಿಯಲ್ಲಿ ಮತ್ತು ಬಾಗಿಲಿನ ತೋರಣದಲ್ಲಿ ಇಡುತ್ತಾರೆ; ಮಂಗಳಕರವೆಂದು ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಹೊಸ ಆರಂಭಗಳೊಂದಿಗೆ ಸಂಬಂಧ ಹೊಂದಿವೆ |
| **ತೆಂಗಿನಕಾಯಿ (ಶ್ರೀಫಲ)** | ಪವಿತ್ರ ಅರ್ಪಣೆ; ಕಳಶದ ಮೇಲೆ ಇಡುತ್ತಾರೆ ಅಥವಾ ಅರ್ಪಣೆಯಾಗಿ ಒಡೆಯುತ್ತಾರೆ |

| **ಮೌಲಿ / ಕಲಾವಾ** | ರಕ್ಷಣೆಗಾಗಿ ಮತ್ತು ಸಂಕಲ್ಪದ ಸಂಕೇತವಾಗಿ ಮಣಿಕಟ್ಟಿಗೆ ಹಾಗೂ ಕಳಶದ ಸುತ್ತ ಕಟ್ಟುವ ಕೆಂಪು ಮತ್ತು ಹಳದಿ ಬಣ್ಣದ ಪವಿತ್ರ ದಾರ |
| **ಪಂಚಾಮೃತ** | ಹಾಲು, ಮೊಸರು, ತುಪ್ಪ, ಜೇನುತುಪ್ಪ ಮತ್ತು ಸಕ್ಕರೆಯ ಮಿಶ್ರಣ; ಮೂರ್ತಿಗಳಿಗೆ ಅಭಿಷೇಕ ಮಾಡಲು ಬಳಸುತ್ತಾರೆ ಮತ್ತು ಪ್ರಸಾದವಾಗಿ ಹಂಚುತ್ತಾರೆ |
| **ಗಂಗಾಜಲ** | ಗಂಗಾ ನದಿಯ ನೀರು; ಅನೇಕ ಮನೆಗಳಲ್ಲಿ ಶುದ್ಧೀಕರಣಕ್ಕೆ ಬಳಸುತ್ತಾರೆ |
| **ಜನಿವಾರ** | ಕೆಲವು ಪೂಜೆಗಳಲ್ಲಿ ದೇವರಿಗೆ ಅರ್ಪಿಸುವ ಪವಿತ್ರ ದಾರ |
| **ಬಟ್ಟೆ (ವಸ್ತ್ರ)** | ಸಾಮಾನ್ಯವಾಗಿ ಕೆಂಪು ಅಥವಾ ಹಳದಿ ಬಣ್ಣದ ಹೊಸ ಬಟ್ಟೆಯ ತುಂಡು; ದೇವರಿಗೆ ಅರ್ಪಿಸುತ್ತಾರೆ ಅಥವಾ ಪೂಜಾ ಪೀಠವನ್ನು ಮುಚ್ಚಲು ಬಳಸುತ್ತಾರೆ |
| **ತುಳಸಿ ಎಲೆಗಳು** | ವಿಷ್ಣು ಮತ್ತು ಕೃಷ್ಣನಿಗೆ ಅರ್ಪಿಸುತ್ತಾರೆ; ಸಾಂಪ್ರದಾಯಿಕವಾಗಿ ಗಣೇಶನಿಗೆ ಅರ್ಪಿಸುವುದಿಲ್ಲ |
| **ಬಿಲ್ವ ಎಲೆಗಳು** | ಶಿವನಿಗೆ ಅರ್ಪಿಸುತ್ತಾರೆ |
| **ಗರಿಕೆ ಹುಲ್ಲು** | ಗಣೇಶನಿಗೆ ಅರ್ಪಿಸುತ್ತಾರೆ |
| **ದಕ್ಷಿಣೆ** | ಹಣದ ಅರ್ಪಣೆ; ಸಾಂಪ್ರದಾಯಿಕವಾಗಿ ಪುರೋಹಿತರಿಗೆ ನೀಡುತ್ತಾರೆ |

## ಹವನಕ್ಕೆ

ಹವನಕ್ಕೆ (ಅಗ್ನಿ ವಿಧಿ) ಅದರದೇ ಆದ ಕೆಲವು ಸಾಮಗ್ರಿಗಳು ಬೇಕಾಗುತ್ತವೆ:

- **ಹವನ ಕುಂಡ**: ಬೆಂಕಿಗಾಗಿ ಬಳಸುವ, ಸಾಮಾನ್ಯವಾಗಿ ಮೆಟ್ಟಿಲಿನಾಕಾರದ ತಾಮ್ರ ಅಥವಾ ಕಬ್ಬಿಣದ ಪಾತ್ರೆ
- **ಸಮಿಧೆ**: ಒಣ ಮರದ ಕಡ್ಡಿಗಳು, ಸಾಮಾನ್ಯವಾಗಿ ಮಾವಿನ ಮರದವು
- **ಹವನ ಸಾಮಗ್ರಿ**: ಗಿಡಮೂಲಿಕೆಗಳು, ಧಾನ್ಯಗಳು, ಸಕ್ಕರೆ ಮತ್ತು ರಾಳಗಳನ್ನು ಸೇರಿಸಿ ಸಿದ್ಧಪಡಿಸಿದ ಮಿಶ್ರಣ
- **ತುಪ್ಪ**: ಚಮಚದಿಂದ ಬೆಂಕಿಗೆ ಅರ್ಪಿಸಲಾಗುತ್ತದೆ
- **ನವಧಾನ್ಯ**: 9 ಗ್ರಹಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ 9 ಧಾನ್ಯಗಳು, ಕೆಲವು ಪೂಜೆಗಳಲ್ಲಿ ಬಳಸಲಾಗುತ್ತವೆ

## ಖರೀದಿ ಮತ್ತು ಸಂಗ್ರಹಣೆ

- **ತಾಜಾವಾಗಿ ಖರೀದಿಸಿ**: ಹೂವುಗಳು, ಹಣ್ಣುಗಳು ಮತ್ತು ವೀಳ್ಯದೆಲೆಗಳಂತಹ ಬಳಸಿ ಮುಗಿಯುವ ಸಾಮಗ್ರಿಗಳನ್ನು ಪೂಜೆಯ ದಿನಕ್ಕೆ ಹತ್ತಿರವಾಗಿ ಖರೀದಿಸಿ.
- **ಪುಡಿಗಳನ್ನು ಪರಿಶೀಲಿಸಿ**: ಅವುಗಳಲ್ಲಿ ಕೃತಕ ಬಣ್ಣಗಳಿವೆಯೇ ನೋಡಿ; ಅನೇಕ ಕುಟುಂಬಗಳು ನೈಸರ್ಗಿಕ ಕುಂಕುಮ ಮತ್ತು ಅರಿಶಿನವನ್ನು ಇಷ್ಟಪಡುತ್ತವೆ.
- **ದೀರ್ಘಕಾಲ ಬಳಸುವ ಸಾಮಗ್ರಿಗಳನ್ನು ಒಟ್ಟಿಗೆ ಇಡಿ**, ಪೂಜೆಯ ಸ್ಥಳದಲ್ಲಿ ಸ್ವಚ್ಛವಾಗಿ ಮತ್ತು ಒಣಗಿರುವಂತೆ; [ಪೂಜಾ ಕೋಣೆಯ ವಾಸ್ತು](/blog/pooja-room-vastu) ನೋಡಿ.
- **ಯಾರು ಏನನ್ನು ಒದಗಿಸುತ್ತಾರೆ ಎಂದು ಕೇಳಿ.** ದೊಡ್ಡ ಸಮಾರಂಭಗಳಿಗೆ ಪಂಡಿತರು ಪೂಜಾ ಸಾಮಗ್ರಿಗಳನ್ನು ತರುತ್ತಾರೆಯೇ ಅಥವಾ ನೀವೇ ವ್ಯವಸ್ಥೆ ಮಾಡಬೇಕೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ; ನಮ್ಮ [ಪೂಜೆಗೆ ಪಂಡಿತರನ್ನು ಬುಕ್ ಮಾಡುವ ಮಾರ್ಗದರ್ಶಿ](/blog/how-to-book-pandit-for-puja-at-home) ಇದರ ಬಗ್ಗೆ ವಿವರಿಸುತ್ತದೆ.

## ಪೂಜೆಯ ನಂತರ

ಪೂಜೆಯಲ್ಲಿ ಬಳಸಿದ ಹೂವುಗಳು, ಎಲೆಗಳು ಮತ್ತು ಅಕ್ಕಿಯನ್ನು ಕಸದ ಬುಟ್ಟಿಗೆ ಎಸೆಯುವ ಬದಲು ಗೌರವದಿಂದ ವಿಲೇವಾರಿ ಮಾಡುವುದು ಸಂಪ್ರದಾಯ. ಈಗ ಅನೇಕ ಕುಟುಂಬಗಳು ಅವನ್ನು ನದಿ, ಕೆರೆಗಳಿಗೆ ಹಾಕುವ ಬದಲು **ಗೊಬ್ಬರವಾಗಿಸುತ್ತಾರೆ ಅಥವಾ ತೋಟದಲ್ಲಿ ಹೂಳುತ್ತಾರೆ**. ಇದರಿಂದ ಸಂಪ್ರದಾಯದ ಆಶಯವನ್ನು ಉಳಿಸಿಕೊಂಡೇ ಮಾಲಿನ್ಯವನ್ನು ತಪ್ಪಿಸಬಹುದು. ಹವನದ ಬೂದಿಯನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ತೋಟದಲ್ಲಿ ಅಥವಾ ಗಿಡದ ಕುಂಡದಲ್ಲಿ ಚೆಲ್ಲುತ್ತಾರೆ.

ಶೀಘ್ರದಲ್ಲೇ ಬರಲಿರುವ Aroha Pujaದಲ್ಲಿ, ಪ್ರತಿ ಬುಕಿಂಗ್‌ಗೆ ಪಂಡಿತರು ಎಲ್ಲಾ ಪೂಜಾ ಸಾಮಗ್ರಿಗಳನ್ನು ತರಬೇಕೇ ಅಥವಾ ಪಟ್ಟಿಯ ಪ್ರಕಾರ ನಿಮ್ಮ ಕುಟುಂಬವೇ ಅವುಗಳನ್ನು ವ್ಯವಸ್ಥೆ ಮಾಡಬೇಕೇ ಎಂಬುದನ್ನು ನೀವು ಆಯ್ಕೆ ಮಾಡಬಹುದು. ನಿಮ್ಮ ಆಯ್ಕೆಗೆ ಅನುಗುಣವಾಗಿ ಬೆಲೆ ಇರುತ್ತದೆ.
