"ಆಗ್ನೇಯದಲ್ಲಿ ಅಡುಗೆಮನೆ"ಯಿಂದ "ಮಧ್ಯಭಾಗವನ್ನು ತೆರೆದಿಡಿ"ಯವರೆಗೆ, ಪ್ರತಿಯೊಂದು ವಾಸ್ತು ಸಲಹೆಯೂ ನಿಮ್ಮ ಮನೆಯ ಯಾವ ಭಾಗ ಎಲ್ಲಿದೆ ಎಂಬುದು ನಿಮಗೆ ತಿಳಿದಿದೆ ಎಂದು ಊಹಿಸುತ್ತದೆ. ಅದಕ್ಕಾಗಿಯೇ ನೆಲವಿನ್ಯಾಸದ ನಕ್ಷೆಯನ್ನು ಓದುವುದು ಮುಖ್ಯ. ಒಂದು ನಕ್ಷೆ, ಅಳತೆಪಟ್ಟಿ ಮತ್ತು ದಿಕ್ಸೂಚಿಯೊಂದಿಗೆ ಇದಕ್ಕೆ ಸುಮಾರು 20 ನಿಮಿಷ ಬೇಕಾಗುತ್ತದೆ, ಮತ್ತು ನೀವು ಇದನ್ನು ಒಮ್ಮೆ ಮಾತ್ರ ಮಾಡಬೇಕಾಗುತ್ತದೆ.

## ನಿಮಗೆ ಬೇಕಾಗಿರುವುದು

- ಪ್ರಮಾಣಾನುಸಾರ ಇರುವ **ಮನೆಯ ನಕ್ಷೆ**. ವಾಸ್ತುಶಿಲ್ಪಿ ಬಿಡಿಸಿದ ನಕ್ಷೆ ಉತ್ತಮ; ಮೊದಲ ಪರಿಶೀಲನೆಗೆ ಕಟ್ಟಡ ನಿರ್ಮಾಪಕರ ಕರಪತ್ರವೂ ಸಾಕು; ಗ್ರಾಫ್ ಕಾಗದದ ಮೇಲೆ ಎಚ್ಚರಿಕೆಯಿಂದ ಕೈಯಲ್ಲಿ ಬಿಡಿಸಿದ ನಕ್ಷೆಯೂ ಸರಿಹೊಂದುತ್ತದೆ.
- ಒಂದು **ದಿಕ್ಸೂಚಿ**, ಅಥವಾ ಸರಿಯಾಗಿ ಮಾಪನ ಹೊಂದಿಸಿದ ಫೋನ್‌ನ ದಿಕ್ಸೂಚಿ.
- ಪೆನ್ಸಿಲ್ ಮತ್ತು ರೂಲರ್, ಅಥವಾ ಚಿತ್ರ ಬಿಡಿಸುವ ಯಾವುದೇ ಸಾಧನ.

## ಹಂತ 1: ನಕ್ಷೆಯನ್ನು ಉತ್ತರ ದಿಕ್ಕಿಗೆ ಹೊಂದಿಸಿ

ಲೋಹದ ವಸ್ತುಗಳು ಮತ್ತು ಎಲೆಕ್ಟ್ರಾನಿಕ್ ಸಾಧನಗಳಿಂದ ದೂರದಲ್ಲಿ, ಮನೆಯ ಕೇಂದ್ರದಲ್ಲಿ ನಿಂತು ದಿಕ್ಸೂಚಿಯಿಂದ ದಿಕ್ಕನ್ನು ತಿಳಿದುಕೊಳ್ಳಿ. ನಕ್ಷೆಯಲ್ಲಿ ಉತ್ತರ ದಿಕ್ಕನ್ನು ಗುರುತಿಸಿ. ನಕ್ಷೆಯಲ್ಲಿರುವ ಉತ್ತರ ದಿಕ್ಕಿನ ಬಾಣ ಮತ್ತು ಉಪಗ್ರಹ ನಕ್ಷೆಯೊಂದಿಗೆ ಅದನ್ನು ಮತ್ತೊಮ್ಮೆ ಪರಿಶೀಲಿಸಿ. ನಂತರ **ಉತ್ತರ ದಿಕ್ಕು ಮೇಲ್ಭಾಗದಲ್ಲಿ ಬರುವಂತೆ ನಕ್ಷೆಯನ್ನು ಮತ್ತೆ ಬಿಡಿಸಿ ಅಥವಾ ತಿರುಗಿಸಿ**. ನಮ್ಮ [ವಾಸ್ತು ದಿಕ್ಕುಗಳ ಮಾರ್ಗದರ್ಶಿ](/blog/vastu-directions-explained) ಇದನ್ನು ವಿವರವಾಗಿ ತಿಳಿಸುತ್ತದೆ.

## ಹಂತ 2: ಕೇಂದ್ರವನ್ನು ಕಂಡುಹಿಡಿಯಿರಿ

ಕೇಂದ್ರ, ಅಂದರೆ **ಬ್ರಹ್ಮಸ್ಥಾನ**, ಉಳಿದೆಲ್ಲದಕ್ಕೂ ಆಧಾರವಾಗಿದೆ.

- **ಆಯತಾಕಾರದ ನಕ್ಷೆ:** ಎರಡೂ ಕರ್ಣಗಳನ್ನು ಎಳೆಯಿರಿ; ಅವು ಮಧ್ಯದಲ್ಲಿ ಸಂಧಿಸುತ್ತವೆ.
- **L ಆಕಾರದ ಅಥವಾ ಅನಿಯಮಿತ ನಕ್ಷೆ:** ನಕ್ಷೆಯನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಒಳಗೊಳ್ಳುವ ಅತಿ ಚಿಕ್ಕ ಆಯತದ ಕೇಂದ್ರವನ್ನು ಬಳಸಬಹುದು. ಇನ್ನಷ್ಟು ನಿಖರವಾಗಿ ಹೇಳುವುದಾದರೆ, ನಕ್ಷೆಯ ವಿಸ್ತೀರ್ಣದ ಕೇಂದ್ರವನ್ನು ಬಳಸಬಹುದು. ಕತ್ತರಿಸಿದ ಮೂಲೆಗಳು ಮತ್ತು ಹೊರಚಾಚಿದ ಭಾಗಗಳನ್ನು ಹೇಗೆ ಪರಿಗಣಿಸಬೇಕು ಎಂಬುದರಲ್ಲಿ ತಜ್ಞರ ಅಭಿಪ್ರಾಯಗಳು ಬೇರೆಬೇರೆಯಾಗಿರುತ್ತವೆ. ಆದ್ದರಿಂದ ಅನಿಯಮಿತ ನಕ್ಷೆಯ ಕೇಂದ್ರವನ್ನು ಒಂದೇ ನಿಖರ ಬಿಂದುವೆಂದು ಪರಿಗಣಿಸದೆ, ಒಂದು ಪ್ರದೇಶವೆಂದು ಪರಿಗಣಿಸಿ.
- **ಬಾಲ್ಕನಿಗಳು:** ಅವುಗಳನ್ನು ಸೇರಿಸಬೇಕೇ ಎಂದು ನಿರ್ಧರಿಸಿ (ಅನೇಕ ತಜ್ಞರು ಮೇಲ್ಛಾವಣಿಯಿರುವ ಬಾಲ್ಕನಿಗಳನ್ನು ಸೇರಿಸಿ, ತೆರೆದ ಬಾಲ್ಕನಿಗಳನ್ನು ಹೊರಗಿಡುತ್ತಾರೆ). ನಂತರ ಆ ನಿರ್ಧಾರವನ್ನು ಎಲ್ಲೆಡೆ ಒಂದೇ ರೀತಿಯಲ್ಲಿ ಅನ್ವಯಿಸಿ.

ಕೆಲವು ಆಧುನಿಕ ವಾಸ್ತು ತಜ್ಞರು ಇದರ ಬದಲು ಹೆಚ್ಚು ಸೂಕ್ಷ್ಮವಾದ **16-ವಲಯ** ವಿಧಾನವನ್ನು ಬಳಸುತ್ತಾರೆ. ಇದರಲ್ಲಿ ಕೇಂದ್ರದಿಂದ ಪ್ರತಿ 22.5° ಅಂತರಕ್ಕೆ ರೇಖೆಗಳನ್ನು ಎಳೆಯುತ್ತಾರೆ. ವಿಶೇಷವಾಗಿ ದೊಡ್ಡ ಮನೆಗಳಿಗೆ ಇದು ಹೆಚ್ಚಿನ ವಿವರ ನೀಡುತ್ತದೆ. ಆದರೆ ಸಾಂಪ್ರದಾಯಿಕ ಮಾರ್ಗದರ್ಶನವು ಹೆಚ್ಚಾಗಿ ಎಂಟು ದಿಕ್ಕುಗಳು ಮತ್ತು ಕೇಂದ್ರವನ್ನು ಆಧರಿಸಿರುತ್ತದೆ. ಆದ್ದರಿಂದ ಆರಂಭಿಸಲು 3 × 3 ಚೌಕಗಳ ವಿನ್ಯಾಸವೇ ಸೂಕ್ತ.

### ನಿಮ್ಮ ಮನೆ ದಿಕ್ಕುಗಳಿಗೆ ಓರೆಯಾಗಿದ್ದರೆ

ಗೋಡೆಗಳು ಉತ್ತರ ದಿಕ್ಕಿನಿಂದ ಸುಮಾರು 45° ಕೋನದಲ್ಲಿ ಇದ್ದರೆ, ಗ್ರಿಡ್ ಸರಿಯಾಗಿ ಹೊಂದುವುದಿಲ್ಲ. ಗ್ರಿಡ್ ಅನ್ನು ಗೋಡೆಗಳಿಗೆ ಹೊಂದಿಸುವ ಬದಲು, ಮನೆಯ ಮಧ್ಯಭಾಗದಿಂದ ಹೊರಗೆ ಹರಡುವ ರೇಖೆಗಳಾಗಿ ಎಂಟು ದಿಕ್ಕುಗಳನ್ನು ಗುರುತಿಸಿ. ಆಗ ಮನೆಯ **ಮೂಲೆಗಳು** ಉತ್ತರ, ಪೂರ್ವ, ದಕ್ಷಿಣ ಮತ್ತು ಪಶ್ಚಿಮ ದಿಕ್ಕುಗಳಿಗೆ ಮುಖ ಮಾಡಿರುವುದನ್ನು ಕಾಣುತ್ತೀರಿ. ಅದು ಸಹಜ. ವಲಯಗಳು ಎಲ್ಲೆಲ್ಲಿ ಬರುತ್ತವೆಯೋ ಅದರಂತೆ ನೋಡಿ.

## ಹಂತ 4: ಪ್ರತಿ ವಲಯದಲ್ಲಿ ಏನಿದೆ ಎಂದು ಪಟ್ಟಿ ಮಾಡಿ

ಸರಳ ಕೋಷ್ಟಕ ಮಾಡಿ. ಪ್ರತಿ ವಲಯದಲ್ಲಿರುವ ಮುಖ್ಯ ಕೊಠಡಿ ಅಥವಾ ಅಂಶವನ್ನು ಗುರುತಿಸಿ. ಪ್ರವೇಶದ್ವಾರ, ಒಲೆ, ಶೌಚಾಲಯಗಳು ಮತ್ತು ಮೆಟ್ಟಿಲು (ಇದ್ದರೆ) ಎಲ್ಲಿವೆ ಎಂಬುದನ್ನೂ ದಾಖಲಿಸಿ.

| ದಿಕ್ಕು | ಅಲ್ಲಿರುವುದು (ಉದಾಹರಣೆ) |
| --- | --- |
| ಈಶಾನ್ಯ | ಪೂಜೆಯ ಮೂಲೆ, ಕಿಟಕಿ |
| ಉತ್ತರ | ವಾಸದ ಕೋಣೆ |
| ವಾಯವ್ಯ | ಅತಿಥಿಗಳ ಮಲಗುವ ಕೋಣೆ |
| ಪೂರ್ವ | ಮುಖ್ಯ ಪ್ರವೇಶ ದ್ವಾರ |
| ಮಧ್ಯಭಾಗ | ಹಾದಿ |
| ಪಶ್ಚಿಮ | ಸ್ನಾನಗೃಹ |
| ಆಗ್ನೇಯ | ಅಡುಗೆಮನೆ |
| ದಕ್ಷಿಣ | ಊಟದ ಕೋಣೆ |
| ನೈಋತ್ಯ | ಮುಖ್ಯ ಮಲಗುವ ಕೋಣೆ |

## ಹಂತ 5: ಸಾಂಪ್ರದಾಯಿಕ ಮಾರ್ಗದರ್ಶನದೊಂದಿಗೆ ಹೋಲಿಸಿ

| ವಲಯ | ಸಾಂಪ್ರದಾಯಿಕವಾಗಿ ಸೂಕ್ತವಾದವು | ಸಾಮಾನ್ಯವಾಗಿ ತಪ್ಪಿಸುವವು |
| --- | --- | --- |
| **ಈಶಾನ್ಯ** | ಪೂಜೆ, ತೆರೆದ ಜಾಗ, ಕಿಟಕಿಗಳು, ನೀರು | ಶೌಚಾಲಯಗಳು, ಅಡುಗೆಮನೆ, ಭಾರವಾದ ವಸ್ತುಗಳ ಸಂಗ್ರಹ |
| **ಪೂರ್ವ** | ಪ್ರವೇಶದ್ವಾರ, ವಾಸದ ಕೋಣೆ, ಓದುವ ಕೋಣೆ | ಭಾರವಾದ ವಸ್ತುಗಳ ಸಂಗ್ರಹ |
| **ಆಗ್ನೇಯ** | ಅಡುಗೆಮನೆ, ವಿದ್ಯುತ್ ಉಪಕರಣಗಳು | ಪ್ರಧಾನ ಮಲಗುವ ಕೋಣೆ, ನೀರಿನ ಟ್ಯಾಂಕ್‌ಗಳು |

## ಹಂತ 6: ಮುಖ್ಯವಾದುದನ್ನೂ ಮುಖ್ಯವಲ್ಲದ್ದನ್ನೂ ಬೇರ್ಪಡಿಸಿ

ಹೆಚ್ಚಿನವರು ಬಿಟ್ಟುಬಿಡುವ ಹಂತ ಇದೇ, ವಾಸ್ತುವನ್ನು ವಿವೇಕದಿಂದ ನೋಡಲು ನೆರವಾಗುವುದೂ ಇದೇ. ಗಮನಿಸಿದ ಪ್ರತಿಯೊಂದು ಅಂಶವನ್ನೂ ಈ ಎರಡು ಗುಂಪುಗಳಲ್ಲಿ ಒಂದಕ್ಕೆ ಸೇರಿಸಿ:

**ಬದಲಾಯಿಸಲು ಕಷ್ಟವಾದವು** (ಖರೀದಿಸುವ ಅಥವಾ ಕಟ್ಟಿಸುವ ಮೊದಲು ಪರಿಗಣಿಸಬೇಕಾದವು):

- ಪ್ರವೇಶದ್ವಾರದ ದಿಕ್ಕು ಮತ್ತು ಸ್ಥಾನ
- ಅಡುಗೆಮನೆಯ ವಲಯ ಮತ್ತು ಗ್ಯಾಸ್ ಲೈನ್
- ಶೌಚಾಲಯಗಳ ಸ್ಥಾನ
- ಮಧ್ಯಭಾಗ ತೆರೆದಿದೆಯೇ

**ಬದಲಾಯಿಸಲು ಸುಲಭ** (ಮನೆಗೆ ಬಂದ ನಂತರ ಸರಿಹೊಂದಿಸಬಹುದು):

- ಯಾವ ಮಲಗುವ ಕೋಣೆಯನ್ನು ಮುಖ್ಯ ಮಲಗುವ ಕೋಣೆಯಾಗಿ ಬಳಸುತ್ತೀರಿ
- ಹಾಸಿಗೆ, ಸೋಫಾ ಮತ್ತು ವಾರ್ಡ್‌ರೋಬ್‌ಗಳ ಸ್ಥಾನ
- ಪೂಜಾ ಸ್ಥಳ ಎಲ್ಲಿರಬೇಕು
- ಈಶಾನ್ಯ ಭಾಗ ಮತ್ತು ಮಧ್ಯಭಾಗದಲ್ಲಿ ಏನು ಇಡಲಾಗಿದೆ

ಮನೆಯಲ್ಲಿನ ಸಮಸ್ಯೆಗಳು ಎರಡನೇ ಗುಂಪಿನಲ್ಲಷ್ಟೇ ಇದ್ದರೆ, ಬಹುತೇಕ ವಾಸ್ತು ತಜ್ಞರ ಮಾನದಂಡಗಳ ಪ್ರಕಾರ ಅದು ಉತ್ತಮ ಸ್ಥಿತಿಯಲ್ಲಿದೆ.

## ಸ್ವತಂತ್ರ ಮನೆಗಳು ಮತ್ತು ನಿವೇಶನಗಳಿಗೆ

ಸ್ವಂತ ನಿವೇಶನದಲ್ಲಿರುವ ಮನೆಯ ನಕ್ಷೆಯನ್ನು ನೀವು ನೋಡುತ್ತಿದ್ದರೆ, ವಾಸ್ತು ತಜ್ಞರು ನಿವೇಶನವನ್ನೂ ಗಮನಿಸುತ್ತಾರೆ: ಸಾಂಪ್ರದಾಯಿಕವಾಗಿ ಉತ್ತರ ಮತ್ತು ಪೂರ್ವದಲ್ಲಿ ಹೆಚ್ಚು ತೆರೆದ ಜಾಗವಿದೆಯೇ, ದಕ್ಷಿಣ ಮತ್ತು ಪಶ್ಚಿಮದಲ್ಲಿ ಎತ್ತರದ ನೆಲ ಹಾಗೂ ಭಾರವಾದ ಕಟ್ಟಡಗಳಿವೆಯೇ, ನಿವೇಶನದ ಆಕಾರ ಹೇಗಿದೆ ಎಂಬುದನ್ನು ನೋಡುತ್ತಾರೆ. ಮೇಲಿನ ವಿಧಾನವು ಕಟ್ಟಡಕ್ಕೂ ಅನ್ವಯಿಸುತ್ತದೆ.
