ಚಂದ್ರನು ಸುಮಾರು 27⅓ ದಿನಗಳಲ್ಲಿ ಇಡೀ ರಾಶಿಚಕ್ರವನ್ನು ದಾಟುತ್ತಾನೆ. ವೈದಿಕ ಜ್ಯೋತಿಷ್ಯವು ಆ ಪಥವನ್ನು **27 ನಕ್ಷತ್ರಗಳು** ಅಥವಾ ಚಂದ್ರಮಾನದ ವಿಭಾಗಗಳಾಗಿ ವಿಭಜಿಸುತ್ತದೆ. ಪ್ರತಿಯೊಂದೂ ಆಕಾಶದ **13°20′** ಭಾಗವನ್ನು ಆವರಿಸುತ್ತದೆ, ಅಂದರೆ ಚಂದ್ರನ ಪ್ರಯಾಣದ ಪ್ರತಿ ದಿನಕ್ಕೆ ಸರಿಸುಮಾರು ಒಂದರಂತೆ. ಈ ಪುಟದಲ್ಲಿ ಎಲ್ಲಾ 27 ನಕ್ಷತ್ರಗಳನ್ನು, ಜ್ಯೋತಿಷಿಗಳು ಹೆಚ್ಚು ಬಳಸುವ ವಿವರಗಳೊಂದಿಗೆ ಪಟ್ಟಿ ಮಾಡಲಾಗಿದೆ ಮತ್ತು ನಂತರ ಪ್ರತಿ ಅಂಕಣದ ಅರ್ಥವನ್ನು ವಿವರಿಸಲಾಗಿದೆ.

ಈ ವಿಷಯ ನಿಮಗೆ ಹೊಸದಾಗಿದ್ದರೆ, ಮೊದಲು [ನಕ್ಷತ್ರ ಎಂದರೇನು](/blog/what-is-a-nakshatra) ಎಂಬುದನ್ನು ಓದಿ. ಮತ್ತೆ ನೋಡಬೇಕಾದಾಗ ಈ ಪುಟ ನಿಮಗೆ ಉಪಯೋಗವಾಗುತ್ತದೆ.

<KeyTakeaway>
27 ನಕ್ಷತ್ರಗಳು ನಿಗದಿತ ಕ್ರಮದಲ್ಲಿ <strong>ಅಶ್ವಿನಿ</strong> (0° ಮೇಷ) ನಿಂದ <strong>ರೇವತಿ</strong> (ಮೀನದ ಕೊನೆಯವರೆಗೆ) ಇರುತ್ತವೆ. ವಿಂಶೋತ್ತರಿ ಕ್ರಮದ ಪ್ರಕಾರ ಪ್ರತಿಯೊಂದಕ್ಕೂ ಒಂದು ಗ್ರಹಾಧಿಪತಿ, ಒಬ್ಬ ದೇವತೆ, ಒಂದು ಪ್ರತೀಕ ಮತ್ತು 3°20′ ಅಳತೆಯ ನಾಲ್ಕು ಪಾದಗಳಿವೆ. ಜನನ ಸಮಯದಲ್ಲಿ ನಿಮ್ಮ ಚಂದ್ರ ನಿಂತಿದ್ದ ನಕ್ಷತ್ರವೇ ನಿಮ್ಮ <strong>ಜನ್ಮ ನಕ್ಷತ್ರ</strong>ವಾಗಿದೆ.
</KeyTakeaway>

## ಅಂಕಣಗಳನ್ನು ಓದುವುದು

### ವ್ಯಾಪ್ತಿ

ಇದು ವೈದಿಕ ಜ್ಯೋತಿಷ್ಯ ಬಳಸುವ **ತಾರಾಪಥ** ರಾಶಿಚಕ್ರದಲ್ಲಿ ಅಳೆಯಲ್ಪಡುತ್ತದೆ. ಒಂದು ಪಶ್ಚಿಮ (ಟ್ರಾಪಿಕಲ್) ಚಾರ್ಟ್‌ಗೆ ಹೋಲಿಸಿದರೆ ಸ್ಥಾನಗಳು ಸುಮಾರು 24° ಮುಂದೆ ಇರುತ್ತವೆ; ದಯವಿಟ್ಟು [ರಾಶಿ ವಿರುದ್ಧ ಸೂರ್ಯ ಚಿಹ್ನೆ](/blog/rashi-vs-sun-sign) ನೋಡಿ. ನವು ನಕ್ಷತ್ರಗಳು ಒಂದು ರಾಶಿಯಿಂದ ಮುಂದಿನ ರಾಶಿಗೆ ಮುಂದುವರಿಯುತ್ತವೆ, ಇದರ ಕಾರಣದಿಂದಾಗಿ, ಉದಾಹರಣೆಗೆ ಕೃತ್ತಿಕೆಯ ವಿಸ್ತೀರ್ಣ ಮೇಷದಲ್ಲಿ ಪ್ರಾರಂಭವಾಗಿ ವೃಷಭದಲ್ಲಿ ಮುಗಿಯುತ್ತದೆ. ರಾಶಿಗಳು ಮತ್ತು ನಕ್ಷತ್ರಗಳು ಹೇಗೆ ಹೊಂದಿಕೊಳ್ಳುತ್ತವೆ ಎಂಬ ಬಗ್ಗೆ, ದಯವಿಟ್ಟು [ರಾಶಿ ವಿರುದ್ಧ ನಕ್ಷತ್ರ](/blog/rashi-vs-nakshatra) ನೋಡಿ.

### ಅಧಿಪತಿ ಗ್ರಹ

ಈ ಕ್ರಮವನ್ನು ಗಮನಿಸಿ: **ಕೇತು, ಶುಕ್ರ, ಸೂರ್ಯ, ಚಂದ್ರ, ಮಂಗಳ, ರಾಹು, ಗುರು, ಶನಿ, ಬುಧ**, ಇದು 3 ಬಾರಿ ಪುನರಾವರ್ತಿಸುತ್ತದೆ. ಇದೇ [ವಿಂಶೋತ್ತರಿ ದಶೆ](/blog/vimshottari-dasha-guide)ಯ ಕ್ರಮ. ನೀವು ಹುಟ್ಟಿದಾಗ ಚಂದ್ರನಿದ್ದ ನಕ್ಷತ್ರದ ಅಧಿಪತಿ ಗ್ರಹದ ದಶೆಯಿಂದಲೇ ನಿಮ್ಮ ಜೀವನ ಆರಂಭವಾಗುತ್ತದೆ. ಆ ನಕ್ಷತ್ರದಲ್ಲಿ ಚಂದ್ರ ಎಷ್ಟು ದೂರ ಸಾಗಿದ್ದ ಎಂಬುದು ಆ ದಶೆಯಲ್ಲಿ ಎಷ್ಟು ಅವಧಿ ಉಳಿದಿತ್ತು ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ.

### ದೇವತೆ

ಪ್ರತಿ ನಕ್ಷತ್ರಕ್ಕೂ ವೈದಿಕ ದೇವತೆಗಳಲ್ಲಿ ಒಬ್ಬ ಅಧಿದೇವತೆ ಇದ್ದಾರೆ: ಕೃತ್ತಿಕೆಗೆ ಅಗ್ನಿ (ಬೆಂಕಿ), ಆರ್ದ್ರಾಗೆ ರುದ್ರ, ಶ್ರವಣಕ್ಕೆ ವಿಷ್ಣು, ಹೀಗೆ ಮುಂದುವರಿಯುತ್ತದೆ. ನಕ್ಷತ್ರದ ಸಾಂಪ್ರದಾಯಿಕ ಸ್ವಭಾವವನ್ನು ವಿವರಿಸಲು ಜ್ಯೋತಿಷಿಗಳು ಅದರ ಅಧಿದೇವತೆಯನ್ನು ಬಳಸುತ್ತಾರೆ. ಉದಾಹರಣೆಗೆ, ಬಿರುಗಾಳಿಯ ದೇವರಾದ ರುದ್ರ ಅಧಿದೇವತೆಯಾಗಿರುವ ಆರ್ದ್ರಾ ನಕ್ಷತ್ರವನ್ನು ಪ್ರಕ್ಷುಬ್ಧತೆ ಮತ್ತು ನವೀಕರಣದೊಂದಿಗೆ ಸಂಬಂಧಿಸುತ್ತಾರೆ. ಇವುಗಳನ್ನು ಭವಿಷ್ಯವಾಣಿಗಳೆಂದು ಅಲ್ಲ, ಸಂಪ್ರದಾಯದ ಸಾಂಕೇತಿಕ ವಿವರಣೆಗಳೆಂದು ಪರಿಗಣಿಸಿ.

### ಚಿಹ್ನೆ

ಈ ಸಂಕೇತಗಳು ನಕ್ಷತ್ರ ಸಮೂಹದ ಆಕಾರಕ್ಕೆ ಸಂಬಂಧಿಸಿದ, ನೆನಪಿಟ್ಟುಕೊಳ್ಳಲು ಬಳಸುತ್ತಿದ್ದ ಹಳೆಯ ಚಿತ್ರರೂಪಗಳು. ಕೆಲವು ಜೋಡಿಯಾಗಿ ಬರುತ್ತವೆ: ಎರಡು ಫಾಲ್ಗುಣಿ ನಕ್ಷತ್ರಗಳಿಗೆ ಹಾಸಿಗೆಯ ಮುಂಭಾಗದ ಮತ್ತು ಹಿಂಭಾಗದ ಕಾಲುಗಳು, ಎರಡು ಭಾದ್ರಪದ ನಕ್ಷತ್ರಗಳಿಗೆ ಮಂಚದ ಮುಂಭಾಗ ಮತ್ತು ಹಿಂಭಾಗ.

## 3 ಗಣಗಳು

ನಕ್ಷತ್ರಗಳನ್ನು ಸ್ವಭಾವದ ಆಧಾರದ ಮೇಲೂ **ಗಣ**ಗಳಾಗಿ ವಿಂಗಡಿಸಲಾಗುತ್ತದೆ. ಈ ವಿಂಗಡಣೆಯನ್ನು ಮುಖ್ಯವಾಗಿ [ಗುಣ ಮಿಲನ](/blog/guna-milan-ashtakoota-compatibility) ಮೂಲಕ ಹೊಂದಾಣಿಕೆ ಪರಿಶೀಲಿಸಲು ಬಳಸುತ್ತಾರೆ.

| ಗಣ | ನಕ್ಷತ್ರಗಳು |
| --- | --- |
| **ದೇವ** (ದೈವಿಕ) | ಅಶ್ವಿನಿ, ಮೃಗಶಿರ, ಪುನರ್ವಸು, ಪುಷ್ಯ, ಹಸ್ತ, ಸ್ವಾತಿ, ಅನುರಾಧಾ, ಶ್ರವಣ, ರೇವತಿ |
| **ಮಾನುಷ್ಯ** (ಮಾನವ) | ಭರಣಿ, ರೋಹಿಣಿ, ಆರ್ದ್ರಾ, ಪೂರ್ವ ಫಲ್ಗುಣಿ, ಉತ್ತರ ಫಲ್ಗುಣಿ, ಪೂರ್ವಾಷಾಢ, ಉತ್ತರಾಷಾಢ, ಪೂರ್ವ ಭಾದ್ರಪದ, ಉತ್ತರ ಭಾದ್ರಪದ |
| **ರಾಕ್ಷಸ** (ಉಗ್ರ) | ಕೃತ್ತಿಕಾ, ಆಶ್ಲೇಷಾ, ಮಘಾ, ಚಿತ್ರಾ, ವಿಶಾಖಾ, ಜ್ಯೇಷ್ಠಾ, ಮೂಲ, ಧನಿಷ್ಠಾ, ಶತಭಿಷಾ |

"ರಾಕ್ಷಸ" ಎಂಬ ಪದ ಕೇಳಲು ಆತಂಕವಾಗಬಹುದು, ಆದರೆ ಸಂಪ್ರದಾಯದಲ್ಲಿ ಅದು ತೀವ್ರವಾದ, ಸ್ವತಂತ್ರ ಸ್ವಭಾವವನ್ನು ಸೂಚಿಸುತ್ತದೆ, ಕೆಟ್ಟ ವ್ಯಕ್ತಿಯನ್ನೋ ಕೆಟ್ಟ ಜಾತಕವನ್ನೋ ಅಲ್ಲ.

## ಹೆಸರುಗಳ ಹಿಂದಿರುವ ತಾರೆಗಳು

ನಕ್ಷತ್ರಗಳಿಗೆ ನಿಜವಾದ ತಾರಾಗುಚ್ಛಗಳ ಹೆಸರನ್ನು ಇಡಲಾಗಿದೆ, ಅವುಗಳಲ್ಲಿ ಹಲವನ್ನು ರಾತ್ರಿ ಆಕಾಶದಲ್ಲಿ ಸುಲಭವಾಗಿ ಗುರುತಿಸಬಹುದು:

| ನಕ್ಷತ್ರ | ಸಾಮಾನ್ಯವಾಗಿ ಗುರುತಿಸುವ ನಕ್ಷತ್ರ(ಗಳು) |
| --- | --- |
| ಕೃತ್ತಿಕಾ | ಪ್ಲಿಯಾಡೀಸ್ |
| ರೋಹಿಣಿ | ಆಲ್ಡೆಬರಾನ್ |
| ಆರ್ದ್ರಾ | ಬೆಟೆಲ್‌ಜ್ಯೂಸ್ |
| ಪುನರ್ವಸು | ಕ್ಯಾಸ್ಟರ್ ಮತ್ತು ಪೊಲಕ್ಸ್ |
| ಮಘಾ | ರೆಗ್ಯುಲಸ್ |
| ಚಿತ್ರಾ | ಸ್ಪೈಕಾ |
| ಸ್ವಾತಿ | ಆರ್ಕ್ಟುರಸ್ |
| ಜ್ಯೇಷ್ಠಾ | ಆಂಟಾರೆಸ್ |
| ಶ್ರವಣ | ಆಲ್ಟೇರ್ |

ರಾಶಿಚಕ್ರದ ವಿಭಾಗಗಳು ತಲಾ 13°20′ರಷ್ಟು ಸಮಾನ ಭಾಗಗಳಾಗಿವೆ. ಆದ್ದರಿಂದ ಒಂದು ನಕ್ಷತ್ರದ ವಿಭಾಗ ಮತ್ತು ಅದಕ್ಕೆ ಹೆಸರಿನ ಮೂಲವಾದ ನಕ್ಷತ್ರದ ಸ್ಥಾನ ಯಾವಾಗಲೂ ನಿಖರವಾಗಿ ಹೊಂದಿಕೆಯಾಗುವುದಿಲ್ಲ. ಜ್ಯೋತಿಷ್ಯದಲ್ಲಿ ಬಳಸುವುದು ಆ ವಿಭಾಗವನ್ನೇ.

## ಪಾದಗಳು ಮತ್ತು ಹೆಸರಿಡುವ ಅಕ್ಷರಗಳು

ಪ್ರತಿ ನಕ್ಷತ್ರವನ್ನು 3°20′ ಅಳತೆಯ ನಾಲ್ಕು **ಪಾದಗಳಾಗಿ** ವಿಂಗಡಿಸಲಾಗಿದೆ. ಪ್ರತಿ ಪಾದಕ್ಕೂ ಹೆಸರಿಡಲು ಬಳಸುವ ಸಾಂಪ್ರದಾಯಿಕ ಆರಂಭಿಕ ಅಕ್ಷರವಿದೆ. ಉದಾಹರಣೆಗೆ, ಅಶ್ವಿನಿ ನಕ್ಷತ್ರದ ನಾಲ್ಕು ಪಾದಗಳಲ್ಲಿ ಯಾವುದಾದರೂ ಒಂದರಲ್ಲಿ ಚಂದ್ರನಿರುವ ಮಗುವಿಗೆ ಸಾಂಪ್ರದಾಯಿಕವಾಗಿ ಚು, ಚೆ, ಚೋ ಅಥವಾ ಲಾ ಅಕ್ಷರದಿಂದ ಆರಂಭವಾಗುವ ಹೆಸರಿಡಲಾಗುತ್ತದೆ. ಈ ಪದ್ಧತಿಯನ್ನು ಅನುಸರಿಸುವ ಕುಟುಂಬಗಳು ಸಾಮಾನ್ಯವಾಗಿ ನಕ್ಷತ್ರವನ್ನು ಮಾತ್ರವಲ್ಲ, ಪಾದವನ್ನೂ ಕೇಳುತ್ತವೆ.

## ನಿಮ್ಮ ನಕ್ಷತ್ರವನ್ನು ಕಂಡುಹಿಡಿಯುವುದು ಹೇಗೆ

ನಿಮ್ಮ ಜನ್ಮ ದಿನಾಂಕ, ಸಮಯ ಮತ್ತು ಸ್ಥಳ ಬೇಕು, ಏಕೆಂದರೆ ಚಂದ್ರನು ದಿನಕ್ಕೆ ಸುಮಾರು ಒಂದು ನಕ್ಷತ್ರದಷ್ಟು ಚಲಿಸುತ್ತಾನೆ. Arohaದ [ಚಂದ್ರ ರಾಶಿ ಕ್ಯಾಲ್ಕುಲೇಟರ್](/moon-sign) ನಿಮ್ಮ ಚಂದ್ರ ರಾಶಿ ಮತ್ತು ನಕ್ಷತ್ರವನ್ನು ತಿಳಿಸುತ್ತದೆ. Aroha Astrology ಆ್ಯಪ್ ಆ ನಕ್ಷತ್ರದಿಂದ ಆರಂಭವಾಗುವ ದಶಾ ಕಾಲಕ್ರಮವನ್ನು ತೋರಿಸುತ್ತದೆ.
