"દક્ષિણ-પૂર્વમાં રસોડું રાખો"થી લઈને "મધ્ય ભાગ ખુલ્લો રાખો" સુધીની Vastuની દરેક સલાહ એ માનીને આપવામાં આવે છે કે તમારા ઘરના કયા ભાગની કઈ દિશા છે, તે તમને ખબર છે. ફ્લોર પ્લાન વાંચવાનો હેતુ એ જ છે. પ્લાન, માપપટ્ટી અને કંપાસ સાથે આમાં લગભગ 20 મિનિટ લાગે છે, અને તમારે આ માત્ર એક જ વાર કરવાનું હોય છે.

<KeyTakeaway>
Vastu અનુસાર પ્લાન વાંચવા માટે: તેને <strong>સાચા ઉત્તર તરફ ગોઠવો</strong>, તેનું <strong>કેન્દ્ર શોધો</strong>, તેના પર <strong>3 × 3નું ગ્રીડ</strong> મૂકો, <strong>દરેક ઝોનમાં શું આવેલું છે તેની યાદી બનાવો</strong>, પછી પરંપરાગત માર્ગદર્શન સાથે સરખામણી કરો અને જેમાં ફેરફાર કરવો મુશ્કેલ હોય તેવી બાબતો (પ્રવેશદ્વાર, રસોડું, શૌચાલય, કેન્દ્ર) ને તમે ફક્ત ફરી ગોઠવી શકો તેવી બાબતોથી અલગ ગણો.
</KeyTakeaway>

## તમને શું જોઈએ

- સ્કેલ મુજબનો **ફ્લોર પ્લાન**. આર્કિટેક્ટનું ડ્રોઇંગ સૌથી સારું છે; પ્રથમ તપાસ માટે બિલ્ડરની બ્રોશર પણ ચાલશે; ગ્રાફ પેપર પર હાથથી દોરેલું સચોટ સ્કેચ પણ કામ લાગશે.
- એક **કંપાસ**, અથવા યોગ્ય રીતે કેલિબ્રેટ કરેલો ફોન કંપાસ.
- એક પેન્સિલ અને રૂલર, અથવા દોરવા માટેનું કોઈ પણ સાધન.

## પગલું 1: પ્લાનને ઉત્તર દિશા તરફ ગોઠવો

ઘરના કેન્દ્રમાંથી, ધાતુની વસ્તુઓ અને ઇલેક્ટ્રોનિક ઉપકરણોથી દૂર રહીને, કંપાસથી દિશા માપો અને નકશામાં ઉત્તર દિશા ચિહ્નિત કરો. નકશામાં દર્શાવેલા ઉત્તર દિશાના તીર અને સેટેલાઇટ નકશા સાથે તેની ખાતરી કરો. પછી **નકશો ફરી દોરો અથવા ફેરવો, જેથી ઉત્તર દિશા ઉપર આવે**. [વાસ્તુની દિશાઓ](/blog/vastu-directions-explained) વિશેની અમારી માર્ગદર્શિકામાં આ વિગતવાર સમજાવ્યું છે.

## પગલું 2: કેન્દ્ર શોધો

ઘરનું કેન્દ્ર, એટલે કે **બ્રહ્મસ્થાન**, બાકીની બધી બાબતોનો આધાર છે.

- **લંબચોરસ પ્લાન:** બંને વિકર્ણો દોરો; તેઓ કેન્દ્રમાં એકબીજાને છેદે છે.
- **L-આકારનો કે અનિયમિત પ્લાન:** પ્લાનને આવરી લેતા સૌથી નાના લંબચોરસનું કેન્દ્ર લો અથવા, વધુ ચોકસાઈ માટે, પ્લાનના ક્ષેત્રફળનું કેન્દ્ર લો. કપાયેલા ખૂણાઓ અને વધારાના ભાગોને કેવી રીતે ગણવા તે અંગે વાસ્તુના જાણકારોમાં મતભેદ છે, તેથી અનિયમિત પ્લાનના કેન્દ્રને એક ચોક્કસ બિંદુને બદલે એક વિસ્તાર માનો.
- **બાલ્કનીઓ:** તેમને ગણતરીમાં સામેલ કરવી કે નહીં તે નક્કી કરો (ઘણા જાણકારો છતવાળી બાલ્કનીઓ સામેલ કરે છે અને ખુલ્લી બાલ્કનીઓને બાકાત રાખે છે) અને એ નિર્ણય સતત એકસરખી રીતે લાગુ કરો.

## પગલું 3: ગ્રીડ દોરો

નકશાને **ત્રણ સમાન કૉલમ અને ત્રણ સમાન પંક્તિઓમાં** વહેંચો. હવે તમને નવ ક્ષેત્રો મળશે:

<FloorPlan grid caption="ઉદાહરણ તરીકે આપેલા નકશા પર 3 × 3નું ગ્રીડ, જેમાં ઉત્તર ઉપર છે. બહારના આઠ ચોરસ દિશાઓ મુજબના ક્ષેત્રો છે અને વચ્ચેનો ચોરસ બ્રહ્મસ્થાન છે." />

| વાયવ્ય | ઉત્તર | ઈશાન |
| --- | --- | --- |
| **પશ્ચિમ** | **મધ્ય** | **પૂર્વ** |
| **નૈઋત્ય** | **દક્ષિણ** | **આગ્નેય** |

કેટલાક આધુનિક વાસ્તુ નિષ્ણાતો તેના બદલે વધુ વિગતવાર **16-ઝોન** પદ્ધતિ અપનાવે છે, જેમાં કેન્દ્રમાંથી દર 22.5°ના અંતરે રેખાઓ દોરવામાં આવે છે. ખાસ કરીને મોટાં ઘરો માટે તે વધુ વિગત આપે છે, પરંતુ પરંપરાગત માર્ગદર્શન મોટાભાગે આઠ દિશાઓ અને કેન્દ્રના આધારે આપવામાં આવે છે. તેથી શરૂઆત માટે 3 × 3ની ગ્રીડ યોગ્ય છે.

### તમારું ઘર ત્રાંસું હોય તો

જો દીવાલો ઉત્તર દિશાથી લગભગ 45° ત્રાંસી હોય, તો ગ્રીડ બરાબર બંધબેસતું નથી. ગ્રીડને દીવાલો સાથે ગોઠવવાને બદલે, કેન્દ્રમાંથી બહાર નીકળતી રેખાઓ વડે આઠ દિશાઓ દોરો. હવે તમે જોશો કે ઘરના **ખૂણા** ઉત્તર, પૂર્વ, દક્ષિણ અને પશ્ચિમ તરફ છે. આ સામાન્ય છે; ક્ષેત્રો જ્યાં આવે તે મુજબ જ તેમને સમજો.

## પગલું 4: દરેક ક્ષેત્રમાં શું છે તેની યાદી બનાવો

એક સરળ કોષ્ટક બનાવો. દરેક ક્ષેત્રમાં આવેલો મુખ્ય ઓરડો અથવા વિશેષ ભાગ નોંધો. સાથે પ્રવેશદ્વાર, ચૂલો, શૌચાલયો અને સીડી (જો હોય તો) ક્યાં છે તે પણ નોંધો.

| દિશા | ત્યાં શું છે (ઉદાહરણ) |
| --- | --- |
| ઉત્તર-પૂર્વ | પૂજાનો ખૂણો, બારી |
| ઉત્તર | બેઠકખંડ |
| ઉત્તર-પશ્ચિમ | મહેમાનોનો શયનખંડ |
| પૂર્વ | મુખ્ય પ્રવેશદ્વાર |
| મધ્ય ભાગ | પસાર થવાનો રસ્તો |
| પશ્ચિમ | બાથરૂમ |
| દક્ષિણ-પૂર્વ | રસોડું |
| દક્ષિણ | જમવાની જગ્યા |
| દક્ષિણ-પશ્ચિમ | મુખ્ય શયનખંડ |

## પગલું 5: પરંપરાગત માર્ગદર્શન સાથે સરખામણી કરો

| વિસ્તાર | પરંપરાગત રીતે યોગ્ય | સામાન્ય રીતે ટાળવામાં આવે છે |
| --- | --- | --- |
| **ઉત્તર-પૂર્વ** | પૂજાનું સ્થાન, ખુલ્લી જગ્યા, બારીઓ, પાણી | શૌચાલય, રસોડું, ભારે સામાનનો સંગ્રહ |
| **પૂર્વ** | પ્રવેશદ્વાર, બેઠકખંડ, અભ્યાસખંડ | ભારે સામાનનો સંગ્રહ |
| **દક્ષિણ-પૂર્વ** | રસોડું, વીજ ઉપકરણો | મુખ્ય શયનખંડ, પાણીની ટાંકીઓ |
| **દક્ષિણ** | શયનખંડ, સામાનનો સંગ્રહ | મુખ્ય પ્રવેશદ્વાર (લોકપ્રિય સલાહ મુજબ) |
| **દક્ષિણ-પશ્ચિમ** | મુખ્ય શયનખંડ, ભારે ફર્નિચર | પ્રવેશદ્વાર, શૌચાલય, ખુલ્લી જગ્યા |
| **પશ્ચિમ** | ભોજનખંડ, બાળકોનો ઓરડો | કંઈ નહીં |
| **ઉત્તર-પશ્ચિમ** | મહેમાનોનો ઓરડો, સ્નાનગૃહ, સામાનનો સંગ્રહ | કંઈ નહીં |
| **ઉત્તર** | પ્રવેશદ્વાર, બેઠકખંડ, ખુલ્લી જગ્યા | ભારે સામાનનો સંગ્રહ |
| **મધ્ય ભાગ** | ખુલ્લી જગ્યા | શૌચાલય, સીડીઓ, ભારે દીવાલો |

અમારી દરેક રૂમ માટેની માર્ગદર્શિકામાં વધુ વિગત છે: [પ્રવેશદ્વાર](/blog/main-entrance-vastu), [રસોડું](/blog/kitchen-vastu), [બેડરૂમ](/blog/bedroom-vastu), [લિવિંગ રૂમ](/blog/living-room-vastu) અને [પૂજા રૂમ](/blog/pooja-room-vastu).

## પગલું 6: શું મહત્ત્વનું છે અને શું નથી તે નક્કી કરો

મોટાભાગના લોકો આ પગલું છોડી દે છે, પણ વાસ્તુને સમજદારીથી જોવામાં આ જ પગલું મદદ કરે છે. દરેક નિરીક્ષણને 2માંથી એક જૂથમાં મૂકો:

**બદલવું મુશ્કેલ છે** (ખરીદતા કે બાંધતા પહેલાં ધ્યાનમાં લેવા જેવી બાબતો):

- પ્રવેશદ્વાર કઈ દિશામાં અને ક્યાં છે
- રસોડું કયા ભાગમાં છે અને ગેસની લાઇન ક્યાં છે
- શૌચાલય ક્યાં છે
- ઘરનો મધ્ય ભાગ ખુલ્લો છે કે નહીં

**બદલવું સરળ છે** (ઘરમાં રહેવા આવ્યા પછી ગોઠવી શકાય):

- કયા બેડરૂમનો ઉપયોગ તમે મુખ્ય બેડરૂમ તરીકે કરો છો
- પલંગ, સોફા અને કપાટ ક્યાં રાખો છો
- પૂજાનું સ્થાન ક્યાં રાખો છો
- ઈશાન ખૂણા અને મધ્ય ભાગમાં શું રાખો છો

જો ઘરમાં સમસ્યાઓ ફક્ત બીજા જૂથની બાબતોમાં હોય, તો મોટાભાગના વાસ્તુ નિષ્ણાતોના મતે ઘર સારી સ્થિતિમાં છે.

## સ્વતંત્ર મકાનો અને પ્લોટ માટે

જો તમે પોતાના પ્લોટ પરના ઘરનો નકશો વાંચી રહ્યા હો, તો વાસ્તુના જાણકારો પ્લોટને પણ ધ્યાનમાં લે છે: પરંપરાગત રીતે ઉત્તર અને પૂર્વ તરફ વધુ ખુલ્લી જગ્યા, દક્ષિણ અને પશ્ચિમ તરફ ઊંચી જમીન અને ભારે બાંધકામ, તેમજ પ્લોટનો આકાર. ઉપરની પદ્ધતિ મકાનને પણ લાગુ પડે છે.
