*સામગ્રી* એટલે પૂજા પહેલાં ભેગી કરવાની વસ્તુઓ. રોજની પૂજા માટે થોડી જ વસ્તુઓ જોઈએ, જ્યારે ગૃહ પ્રવેશ કે હવન માટે ઘણી વસ્તુઓ જોઈએ. દરેક વસ્તુનું પરંપરાગત મહત્ત્વ છે. એ જાણવાથી વિધિ માત્ર ખરીદીની યાદી બની રહેતી નથી.

રીત રિવાજો પ્રદેશ, સમુદાય અને દેવતા પ્રમાણે બદલાય છે. તેથી આને સામાન્ય માર્ગદર્શિકા માનો અને તમારા પરિવારની કે પંડિતજીની યાદી અલગ હોય ત્યાં તેને અનુસરો.

<KeyTakeaway>
મૂળભૂત પૂજા સામગ્રીમાં <strong>દીવો</strong>, <strong>ધૂપ</strong>, <strong>પાણી</strong>, <strong>કંકુ અને હળદર</strong>, <strong>અક્ષત</strong> (આખા ચોખા), <strong>ફૂલો</strong> અને <strong>ખાદ્ય નૈવેદ્ય</strong> હોય છે. આ બધું <strong>થાળી</strong>માં રાખવામાં આવે છે. મોટી પૂજાવિધિઓમાં <strong>કળશ</strong>, <strong>નાળિયેર</strong>, <strong>આંબાનાં પાન</strong>, <strong>નાગરવેલનાં પાન અને સોપારી</strong>, <strong>મૌલી</strong>નો દોરો, <strong>પંચામૃત</strong> અને હવન માટે <strong>હવન સામગ્રી</strong> પણ ઉમેરવામાં આવે છે.
</KeyTakeaway>

## રોજિંદી જરૂરી સામગ્રી

| વસ્તુ | તે શું છે | પરંપરાગત મહત્ત્વ |
| --- | --- | --- |
| **દીવો** | ઘી અથવા તેલમાં કપાસની વાટવાળો માટી કે પિત્તળનો દીવો | પ્રકાશ અંધકાર દૂર કરે છે; જ્યોતને પૂજાની સાક્ષી માનવામાં આવે છે |
| **અગરબત્તી / ધૂપ** | અગરબત્તીઓ અથવા ધૂપની શંકુ આકારની ગોળીઓ | દેવતાને અર્પણ થતી સુગંધ; પાંચ મૂળભૂત અર્પણોમાંનું એક |
| **પાણી (જળ)** | નાના વાસણ (*લોટા*)માં સ્વચ્છ પાણી | શુદ્ધિકરણ; ઉપચારોમાં ધોવા અને આચમન માટે અર્પણ થાય છે |
| **કુમકુમ / રોળી** | લાલ ચૂર્ણ | શુભતાનું પ્રતીક; દેવતાને ચડાવવામાં અને તિલક તરીકે લગાવવામાં આવે છે |
| **હળદર** | હળદર | શુદ્ધતા અને શુભતા |
| **ચંદન** | ચંદનનો લેપ | ઠંડક આપતું, સુગંધિત અર્પણ (*ગંધ*) |
| **અક્ષત** | આખા, ન તૂટેલા ચોખા, જેમાં ઘણી વાર કુમકુમ ભેળવવામાં આવે છે | પૂર્ણતા અને સમૃદ્ધિ |
| **ફૂલો** | તાજાં ફૂલો અને હાર | સૌંદર્ય અને ભક્તિ; અમુક ફૂલો અમુક દેવતાઓ સાથે સંકળાયેલાં છે |
| **નૈવેદ્ય** | ફળ, મીઠાઈ, દૂધ અથવા રાંધેલું ભોજન | દેવતાને અર્પણ કરેલું ભોજન, જે પછી પ્રસાદ તરીકે વહેંચવામાં આવે છે |
| **ઘંટડી** | હાથમાં પકડીને વગાડવાની નાની ઘંટડી | પૂજાની શરૂઆતમાં અને આરતી દરમિયાન વગાડવામાં આવે છે |
| **થાળી** | થાળી, ઘણી વાર પિત્તળ કે સ્ટીલની | તેમાં પૂજાની વસ્તુઓ રાખવામાં આવે છે; આરતી માટે વપરાય છે |
| **કપૂર** | કપૂરની સફેદ ગોળીઓ | આરતી દરમિયાન બાળવામાં આવે છે; તે કોઈ અવશેષ છોડતું નથી, જેને ઘણી વાર અહંકાર ઓગળી જવાના પ્રતીક તરીકે જોવામાં આવે છે |

## મોટી પૂજાઓ માટેની સામગ્રી

| વસ્તુ | પરંપરાગત મહત્ત્વ |
| --- | --- |
| **કળશ** | પાણીથી ભરેલું પાત્ર, જે પૂર્ણતા અને ઈશ્વરની હાજરીનું પ્રતીક છે; ઘણી વિધિઓમાં તેનું મુખ્ય સ્થાન છે |
| **આંબાના પાન** | કળશના મુખ પર અને દરવાજાના તોરણમાં મૂકવામાં આવે છે; શુભ માનવામાં આવે છે અને નવી શરૂઆત સાથે સંકળાયેલા છે |
| **નારિયેળ (શ્રીફળ)** | પવિત્ર અર્પણ; કળશ પર મૂકવામાં આવે છે અથવા અર્પણ તરીકે વધેરવામાં આવે છે |
| **પાન અને સોપારી (પાન, સોપારી)** | આદર દર્શાવવા *તાંબૂલ* તરીકે અર્પણ કરવામાં આવે છે; ક્યારેક સોપારીની ગણેશજી તરીકે પૂજા કરવામાં આવે છે |
| **મૌલી / કલાવા** | લાલ અને પીળો પવિત્ર દોરો, જે રક્ષણ અને સંકલ્પના પ્રતીક તરીકે કાંડા પર અને કળશની આસપાસ બાંધવામાં આવે છે |
| **પંચામૃત** | દૂધ, દહીં, ઘી, મધ અને ખાંડનું મિશ્રણ, જેનાથી મૂર્તિઓને સ્નાન કરાવવામાં આવે છે અને જેને પ્રસાદ તરીકે વહેંચવામાં આવે છે |
| **ગંગાજળ** | ગંગાનું પાણી, જેનો ઘણાં ઘરોમાં શુદ્ધિકરણ માટે ઉપયોગ થાય છે |
| **જનોઈ** | કેટલીક પૂજાઓમાં દેવતાને અર્પણ કરવામાં આવતો પવિત્ર દોરો |
| **વસ્ત્ર** | નવા કાપડનો ટુકડો, સામાન્ય રીતે લાલ કે પીળો, જે દેવતાને અર્પણ કરવામાં આવે છે અથવા પૂજાની વેદી ઢાંકવા વપરાય છે |
| **તુલસીનાં પાન** | વિષ્ણુ અને કૃષ્ણને અર્પણ કરવામાં આવે છે; પરંપરા મુજબ ગણેશજીને અર્પણ કરવામાં આવતાં નથી |
| **બિલીપત્ર** | શિવજીને અર્પણ કરવામાં આવે છે |
| **દૂર્વા** | ગણેશજીને અર્પણ કરવામાં આવે છે |
| **દક્ષિણા** | પૈસાની ભેટ, જે પરંપરા મુજબ પૂજારીને આપવામાં આવે છે |

## હવન માટે

હવન (અગ્નિ વિધિ) માટે આ સામગ્રી પણ જોઈએ:

- **હવન કુંડ**: અગ્નિ માટેનું તાંબા અથવા લોખંડનું પાત્ર, જે ઘણી વાર પગથિયાં જેવા આકારનું હોય છે
- **સમિધા**: લાકડાની સૂકી સળીઓ, સામાન્ય રીતે આંબાની
- **હવન સામગ્રી**: જડીબુટ્ટીઓ, અનાજ, ખાંડ અને રાળનું તૈયાર મિશ્રણ
- **ઘી**: ચમચી વડે અગ્નિમાં અર્પણ કરવામાં આવે છે
- **નવધાન્ય**: નવ ગ્રહો સાથે સંકળાયેલાં નવ અનાજ, જે કેટલીક પૂજાઓમાં વપરાય છે

[ગૃહપ્રવેશ](/blog/griha-pravesh-puja) અથવા [વાસ્તુ શાંતિ](/blog/vastu-shanti-puja) માટે ઉપર આપેલી મોટી પૂજાની યાદી ઉપરાંત તોરણ, દૂધ ઉકાળવા માટે નવું વાસણ અને હવનની સામગ્રીની જરૂર પડશે. [વાહન પૂજા](/blog/vahan-puja-new-vehicle) માટે સામાન્ય રીતે નાળિયેર, માળા, લીંબુ અને મૌલી ઉમેરવામાં આવે છે. તમારી પરંપરા મુજબની આખરી યાદી સામાન્ય રીતે તમારા પંડિત આપશે.

## ખરીદી અને સંગ્રહ

- **વપરાઈ જતી વસ્તુઓ તાજી ખરીદો**: ફૂલ, ફળ અને નાગરવેલનાં પાન પૂજાના દિવસની નજીક ખરીદો.
- **પાઉડરમાં કૃત્રિમ રંગો છે કે નહીં તે તપાસો**; ઘણાં પરિવારો કુદરતી કુમકુમ અને હળદર પસંદ કરે છે.
- **લાંબો સમય ટકતી વસ્તુઓ એકસાથે રાખો**, પૂજાની જગ્યામાં સ્વચ્છ અને સૂકી રાખો; [પૂજાના રૂમ માટે વાસ્તુ](/blog/pooja-room-vastu) જુઓ.
- **કોણ શું લાવશે તે પૂછો.** મોટી વિધિઓ માટે, પંડિત સામગ્રી લાવશે કે તમારે તેની વ્યવસ્થા કરવાની છે તે નક્કી કરી લો; [પંડિત બુક કરાવવા](/blog/how-to-book-pandit-for-puja-at-home) વિશેની અમારી માર્ગદર્શિકામાં આની માહિતી છે.

## પૂજા પછી

પૂજામાં વપરાયેલાં ફૂલો, પાંદડાં અને ચોખાને કચરાપેટીમાં ફેંકી દેવાને બદલે પરંપરાગત રીતે આદરપૂર્વક રાખવામાં આવે છે. ઘણાં પરિવારો હવે તેમને નદીઓ અને તળાવોમાં નાખવાને બદલે **તેનું ખાતર બનાવે છે અથવા બગીચામાં દાટી દે છે**, જેથી પ્રદૂષણ ટળે છે અને પરંપરાની ભાવના પણ જળવાય છે. હવનની રાખ ઘણી વાર બગીચામાં અથવા છોડના કૂંડામાં પાથરવામાં આવે છે.

ટૂંક સમયમાં આવી રહેલી Aroha Puja પર તમે દરેક બુકિંગ માટે પસંદ કરી શકશો: પંડિત બધી પૂજા સામગ્રી લઈને આવે અથવા તમારું કુટુંબ યાદી મુજબ તેની વ્યવસ્થા કરે. કિંમત તમારી પસંદગી મુજબ હશે.
