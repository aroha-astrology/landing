*Samagri* significa simplemente materiales, las cosas que reúnes antes de una puja. Para una puja diaria bastan unos pocos; para un Griha Pravesh o un havan hacen falta docenas. Cada elemento tiene un significado tradicional, y conocerlo hace que el ritual sea algo más que una lista de compras.

Las prácticas varían según la región, la comunidad y la deidad, así que toma esto como una guía general y sigue la lista de tu familia o de tu pandit cuando sea diferente.

<KeyTakeaway>
Un kit básico incluye una <strong>diya</strong>, <strong>incienso</strong>, <strong>agua</strong>, <strong>kumkum y haldi</strong>, <strong>akshata</strong> (arroz entero), <strong>flores</strong> y una <strong>ofrenda de comida</strong>, todo sobre una <strong>thali</strong>. Las ceremonias más grandes añaden un <strong>kalash</strong>, un <strong>coco</strong>, <strong>hojas de mango</strong>, <strong>hojas de betel y nueces de areca</strong>, hilo <strong>mauli</strong>, <strong>panchamrit</strong> y, para un havan, <strong>havan samagri</strong>.
</KeyTakeaway>

## Los elementos esenciales de cada día

| Artículo | Qué es | Significado tradicional |
| --- | --- | --- |
| **Diya** | Una lámpara de barro o latón con una mecha de algodón en ghee o aceite | La luz disipa la oscuridad; la llama se considera testigo de la puja |
| **Agarbatti / dhoop** | Varillas o conos de incienso | Fragancia ofrecida a la deidad; una de las cinco ofrendas básicas |
| **Agua (jal)** | Agua limpia en un recipiente pequeño (*lota*) | Purificación; se ofrece para lavar y beber durante los upacharas |
| **Kumkum / roli** | Polvo rojo | Buen augurio; se aplica a la deidad y como tilak |
| **Haldi** | Cúrcuma | Pureza y buen augurio |
| **Chandan** | Pasta de sándalo | Una ofrenda fresca y fragante (*gandha*) |
| **Akshata** | Arroz de granos enteros, a menudo mezclado con kumkum | Plenitud y prosperidad |
| **Flores** | Flores frescas y guirnaldas | Belleza y devoción; ciertas flores se asocian con ciertas deidades |
| **Naivedya** | Fruta, dulces, leche o comida preparada | Comida ofrecida a la deidad que luego se comparte como prasad |
| **Campana (ghanti)** | Una pequeña campana de mano | Se hace sonar al comenzar el culto y durante el aarti |
| **Thali** | Un plato, a menudo de latón o acero | Sostiene los artículos; se usa para el aarti |
| **Alcanfor (karpur)** | Pastillas blancas de alcanfor | Se quema durante el aarti; no deja residuos, lo que suele interpretarse como un símbolo de la disolución del ego |

## Elementos para pujas más grandes

| Elemento | Significado tradicional |
| --- | --- |
| **Kalash** | Recipiente con agua que representa la plenitud y la presencia de la divinidad; ocupa un lugar central en muchas ceremonias |
| **Hojas de mango** | Se colocan en la boca del kalash y en el toran de la puerta; son auspiciosas y se asocian con los nuevos comienzos |
| **Coco (shriphal)** | Una ofrenda pura; se coloca sobre el kalash o se rompe como ofrenda |
| **Hojas y nueces de betel (paan, supari)** | Se ofrecen como *tambula*, en señal de respeto; a veces se venera una supari como representación de Ganesha |
| **Mauli / kalava** | Hilo sagrado rojo y amarillo que se ata a la muñeca y alrededor del kalash, como protección y señal de un voto |
| **Panchamrit** | Mezcla de leche, cuajada, ghee, miel y azúcar que se usa para bañar las imágenes de las deidades y se comparte como prasad |
| **Gangajal** | Agua del Ganges que se usa para la purificación en muchos hogares |
| **Janeu** | Hilo sagrado que se ofrece a la deidad en algunas pujas |
| **Tela (vastra)** | Trozo de tela nueva, generalmente roja o amarilla, que se ofrece a la deidad o se usa para cubrir el altar |
| **Hojas de tulsi** | Se ofrecen a Vishnu y Krishna; tradicionalmente no se ofrecen a Ganesha |
| **Hojas de bel (bilva)** | Se ofrecen a Shiva |
| **Hierba durva** | Se ofrece a Ganesha |
| **Dakshina** | Ofrenda de dinero que tradicionalmente se entrega al sacerdote |

## Para un havan

Un havan (ritual de fuego) requiere sus propios elementos:

- **Havan kund**: un recipiente de cobre o hierro, a menudo escalonado, para el fuego
- **Samidha**: ramitas secas de madera, generalmente de mango
- **Havan samagri**: una mezcla preparada de hierbas, granos, azúcar y resinas
- **Ghee**: se ofrece al fuego con una cuchara
- **Navadhanya**: nueve granos asociados con los nueve planetas, utilizados en algunas pujas

## Compra y conservación

- **Compre los productos perecederos poco antes**: flores, frutas y hojas de betel cerca de la fecha.
- **Revise los polvos** para comprobar que no contengan colorantes artificiales; muchas familias prefieren el kumkum y la haldi naturales.
- **Guarde los objetos reutilizables juntos**, limpios y secos, en el espacio de puja; consulte [Vastu para la habitación de puja](/blog/pooja-room-vastu).
- **Pregunte quién aporta cada cosa.** Para ceremonias más grandes, confirme si el pandit lleva la samagri o si debe prepararla usted; nuestra guía sobre [cómo contratar a un pandit](/blog/how-to-book-pandit-for-puja-at-home) explica este punto.

## Después

Las flores, las hojas y el arroz utilizados se tratan tradicionalmente con respeto, en lugar de tirarlos a la basura. Muchas familias ahora **los convierten en compost o los entierran en un jardín** en vez de arrojarlos a ríos y lagos. Así evitan la contaminación sin perder el sentido de la costumbre. Las cenizas de un havan suelen esparcirse en un jardín o en una maceta.
