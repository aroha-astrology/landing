"தென்கிழக்கில் சமையலறை" முதல் "மையத்தைத் திறந்தவாறு வைத்திருங்கள்" என்பது வரை ஒவ்வொரு வாஸ்து ஆலோசனையும், உங்கள் வீட்டின் எந்தப் பகுதி எந்தத் திசையில் உள்ளது என்பதை நீங்கள் அறிந்திருக்கிறீர்கள் என்ற அடிப்படையில்தான் வழங்கப்படுகிறது. அதற்காகத்தான் தரைத்தள வரைபடத்தைப் படிக்க வேண்டும். ஒரு வரைபடம், அளவுகோல் மற்றும் திசைகாட்டியுடன் இதைச் செய்ய சுமார் 20 நிமிடங்கள் ஆகும், இதை நீங்கள் ஒருமுறை செய்தால் போதும்.

</KeyTakeaway>

## உங்களுக்கு தேவையானவை

- அளவுகோலுடன் வரையப்பட்ட **தளத் திட்டம்**. கட்டிடக் கலைஞரின் வரைபடம் சிறந்தது; முதல் பார்வைக்குக் கட்டுமான நிறுவனத்தின் சிற்றேடு போதுமானது; கிராப் பேப்பரில் கவனமாகக் கையால் வரைந்ததும் நன்றாகப் பயன்படும்.
- ஒரு **திசைகாட்டி**, அல்லது அளவுத்திருத்தம் செய்யப்பட்ட தொலைபேசி திசைகாட்டி.
- ஒரு பென்சிலும் அளவுகோலும், அல்லது ஏதேனும் வரைதல் கருவியும்.

## படி 1: திட்டத்தை வடக்கு நோக்கி அமைக்கவும்

வீட்டின் மையத்தில், உலோகம் மற்றும் மின்னணு சாதனங்களிலிருந்து விலகி, திசைகாட்டியைப் பயன்படுத்தி திசையை அறிந்து, வரைபடத்தில் வடக்கைக் குறிக்கவும். வரைபடத்தில் உள்ள வடக்கு அம்புக்குறியுடனும் செயற்கைக்கோள் வரைபடத்துடனும் சரிபார்க்கவும். பின்னர் **வரைபடத்தை மறுவரைந்து அல்லது சுழற்றி, வடக்கு மேல்புறத்தில் இருக்குமாறு அமைக்கவும்**. இதைப் பற்றி எங்கள் [வாஸ்து திசைகள்](/blog/vastu-directions-explained) வழிகாட்டியில் விரிவாகப் பார்க்கலாம்.

## படி 2: மையத்தைக் கண்டறியவும்

மையம், அல்லது **பிரம்மஸ்தான்**, மற்ற அனைத்திற்கும் அடிப்படையாக அமைகிறது.

- **செவ்வகத் திட்டம்:** இரு மூலைவிட்டங்களையும் வரையுங்கள்; அவை மையத்தில் ஒன்றையொன்று கடக்கும்.
- **எல் வடிவ அல்லது ஒழுங்கற்ற திட்டம்:** அந்தத் திட்டத்தைச் சுற்றியுள்ள மிகச் சிறிய செவ்வகத்தின் மையத்தைப் பயன்படுத்துங்கள், அல்லது இன்னும் துல்லியமாக, திட்டத்தின் பரப்பளவு மையத்தைப் பயன்படுத்துங்கள். வெட்டப்பட்ட மூலைகளையும் நீட்சிகளையும் எவ்வாறு கையாள வேண்டும் என்பதில் பயிற்சியாளர்களிடையே வேறுபாடு உள்ளது, எனவே ஒழுங்கற்ற திட்டத்தின் மையத்தை ஒரு துல்லியமான புள்ளியாக அல்லாமல் ஒரு மண்டலமாகக் கருதுங்கள்.
- **பால்கனிகள்:** அவற்றைச் சேர்க்க வேண்டுமா என்பதை முடிவு செய்யுங்கள் (பல பயிற்சியாளர்கள் மூடப்பட்ட பால்கனிகளைச் சேர்த்து, திறந்த பால்கனிகளைச் சேர்க்காமல் விடுகிறார்கள்), மேலும் அந்தத் தேர்வைச் சீராகப் பின்பற்றுங்கள்.

## படி 3: கட்டத்தை அமைக்கவும்

திட்ட வரைபடத்தை **சம அளவிலான மூன்று நெடுவரிசைகளாகவும் மூன்று கிடைமட்ட வரிசைகளாகவும்** பிரிக்கவும். இப்போது உங்களிடம் ஒன்பது மண்டலங்கள் உள்ளன:

சில நவீன பயிற்சியாளர்கள் அதற்குப் பதிலாக இன்னும் நுணுக்கமான **16-மண்டல** முறையைப் பயன்படுத்துகின்றனர். மையத்திலிருந்து ஒவ்வொரு 22.5° இடைவெளியிலும் கோடுகளை வரைகின்றனர். இது குறிப்பாகப் பெரிய வீடுகளுக்கு அதிக விவரங்களை வழங்குகிறது. ஆனால் பாரம்பரிய வழிகாட்டுதல்கள் பெரும்பாலும் எட்டு திசைகளையும் மையத்தையும் அடிப்படையாகக் கொண்டே விளக்கப்படுகின்றன. எனவே, 3 × 3 கட்டமே தொடங்குவதற்கு ஏற்றது.

### உங்கள் வீடு கோணமாக இருந்தால்

சுவர்கள் வடக்கிலிருந்து சுமார் 45° சாய்வாக இருந்தால், கட்டம் சரியாகப் பொருந்தாது. கட்டத்தைச் சுவர்களுடன் ஒத்திசைப்பதற்குப் பதிலாக, மையத்திலிருந்து வெளிப்புறமாக விரியும் கோடுகளாக எட்டு திசைகளையும் வரையுங்கள். இப்போது வீட்டின் **மூலைகள்** வடக்கு, கிழக்கு, தெற்கு மற்றும் மேற்குப் பக்கங்களை நோக்கி இருப்பதைப் பார்ப்பீர்கள். இது இயல்பானதே, மண்டலங்கள் அமைந்துள்ளபடியே அவற்றைப் படியுங்கள்.

## படி 4: ஒவ்வொரு மண்டலத்திலும் உள்ளவற்றைப் பட்டியலிடுங்கள்

எளிய அட்டவணையை உருவாக்குங்கள். ஒவ்வொரு மண்டலத்திலும் உள்ள முக்கிய அறை அல்லது அம்சத்தைக் குறித்துக்கொள்ளுங்கள். அதோடு நுழைவாயில், அடுப்பு, கழிப்பறைகள் மற்றும் படிக்கட்டு (ஏதேனும் இருந்தால்) ஆகியவை எங்கு உள்ளன என்பதையும் பதிவு செய்யுங்கள்.

| மண்டலம் | அதில் இருப்பது (உதாரணம்) |
| --- | --- |
| வடகிழக்கு | பூஜை மூலை, ஜன்னல் |
| வடக்கு | வரவேற்பறை |
| வடமேற்கு | விருந்தினர் படுக்கையறை |
| கிழக்கு | பிரதான நுழைவாயில் |
| மையம் | வழித்தடம் |
| மேற்கு | குளியலறை |
| தென்கிழக்கு | சமையலறை |
| தெற்கு | உணவருந்தும் அறை |
| தென்மேற்கு | முதன்மை படுக்கையறை |

## படி 5: பாரம்பரிய வழிகாட்டுதலுடன் ஒப்பிடுங்கள்

| மண்டலம் | பாரம்பரியமாக ஏற்றவை | பொதுவாகத் தவிர்க்கப்படுபவை |
| --- | --- | --- |
| **வடகிழக்கு** | பூஜை, திறந்த வெளி, ஜன்னல்கள், நீர் | கழிப்பறைகள், சமையலறை, கனமான சேமிப்புப் பொருட்கள் |
| **கிழக்கு** | நுழைவாயில், வரவேற்பறை, படிப்பறை | கனமான சேமிப்புப் பொருட்கள் |
| **தென்கிழக்கு** | சமையலறை, மின்சாதனங்கள் | முதன்மை படுக்கையறை, தண்ணீர் தொட்டிகள் |
| **தெற்கு** | படுக்கையறைகள், சேமிப்பிடம் | பிரதான நுழைவாயில் (பிரபலமான ஆலோசனைகளில்) |
| **தென்மேற்கு** | முதன்மை படுக்கையறை, கனமான தளபாடங்கள் | நுழைவாயில், கழிப்பறைகள், திறந்த வெளி |
| **மேற்கு** | உணவருந்தும் அறை, குழந்தைகள் அறை | - |
| **வடமேற்கு** | விருந்தினர் அறை, குளியலறைகள், சேமிப்பிடம் | - |
| **வடக்கு** | நுழைவாயில், வரவேற்பறை, திறந்த வெளி | கனமான சேமிப்புப் பொருட்கள் |
| **மையம்** | திறந்த வெளி | கழிப்பறைகள், படிக்கட்டுகள், கனமான சுவர்கள் |

எங்கள் அறை வழிகாட்டிகள் இன்னும் ஆழமாகச் செல்கின்றன: [நுழைவாயில்](/blog/main-entrance-vastu), [சமையலறை](/blog/kitchen-vastu), [படுக்கையறை](/blog/bedroom-vastu), [வாழும் அறை](/blog/living-room-vastu) மற்றும் [பூஜை அறை](/blog/pooja-room-vastu).

## படி 6: முக்கியமானவற்றை முக்கியமில்லாதவற்றிலிருந்து பிரித்தறியுங்கள்

பெரும்பாலானோர் தவிர்க்கும் படி இதுதான், மேலும் Vastu முறையை நடைமுறைக்கு ஏற்றதாக வைத்திருப்பதும் இதுவே. ஒவ்வொரு கவனிப்பையும் இரண்டு குழுக்களில் ஒன்றில் இடுங்கள்:

**மாற்றுவது கடினம்** (வாங்குவதற்கு அல்லது கட்டுவதற்கு முன் பரிசீலிக்க வேண்டியது):

- நுழைவாயிலின் திசையும் அமைவிடமும்
- சமையலறை அமைந்துள்ள பகுதியும் எரிவாயு இணைப்பும்
- கழிப்பறைகள் அமைந்துள்ள இடங்கள்
- மையப்பகுதி திறந்திருக்கிறதா என்பதும்

**மாற்றுவது எளிது** (நீங்கள் குடியேறிய பிறகு மாற்றியமைக்கலாம்):

- முதன்மைப் படுக்கையறையாக நீங்கள் பயன்படுத்தும் படுக்கையறை
- படுக்கை, சோபா மற்றும் அலமாரியின் அமைவிடங்கள்
- பூஜையறை அமையும் இடம்
- வடகிழக்கிலும் மையப்பகுதியிலும் என்ன சேமித்து வைக்கப்படுகிறது என்பது

ஒரு வீட்டில் இரண்டாவது குழுவில் மட்டுமே பிரச்சினைகள் இருந்தால், பெரும்பாலான வாஸ்து நிபுணர்களின் தரநிலைகளின்படி அது நல்ல நிலையில் உள்ளது.

## தனி வீடுகள் மற்றும் மனைகளுக்கு

ஒரு வீட்டுக்கான தனி மனையில் அமைந்துள்ள வரைபடத்தை நீங்கள் பார்க்கிறீர்கள் என்றால், வாஸ்து நிபுணர்கள் அந்த நிலப்பகுதியையும் கவனிப்பார்கள்: பாரம்பரியமாக வடக்கு மற்றும் கிழக்கில் அதிக திறந்தவெளியும், தெற்கு மற்றும் மேற்கில் உயர்ந்த நிலப்பகுதியும் அதிக எடையுள்ள கட்டமைப்புகளும், மேலும் மனையின் வடிவமும் பார்க்கப்படும். மேலே கூறிய முறை கட்டிடத்திற்கும் பொருந்தும்.

## Aroha மூலம் இதைச் செய்வது
