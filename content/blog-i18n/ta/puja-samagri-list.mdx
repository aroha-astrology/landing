*சாமக்ரி* என்றால் பூஜைக்கு முன் நீங்கள் சேகரிக்கும் பொருட்கள் என்று பொருள். தினசரி பூஜைக்கு அவற்றில் சிலவே போதும்; கிருஹப் பிரவேசம் அல்லது ஹவனத்துக்குப் பல டஜன் பொருட்கள் தேவைப்படும். ஒவ்வொரு பொருளுக்கும் மரபு சார்ந்த அர்த்தம் உண்டு. அதை அறிந்துகொண்டால், பூஜை வெறும் பொருட்களை வாங்கும் பட்டியலாக மட்டும் இருக்காது.

பழக்கவழக்கங்கள் பகுதி, சமூகம், தெய்வம் ஆகியவற்றைப் பொறுத்து மாறுபடும். எனவே இதைப் பொதுவான வழிகாட்டியாக எடுத்துக்கொள்ளுங்கள். வேறுபாடுகள் இருந்தால், உங்கள் குடும்பத்தினர் அல்லது பண்டிதர் தரும் பட்டியலைப் பின்பற்றுங்கள்.

<KeyTakeaway>
ஒரு அடிப்படை பூஜைப் பொருள் தொகுப்பில் <strong>தீபம்</strong>, <strong>ஊதுபத்தி</strong>, <strong>தண்ணீர்</strong>, <strong>குங்குமம் மற்றும் மஞ்சள்</strong>, <strong>அட்சதை</strong> (முழு அரிசி), <strong>மலர்கள்</strong> மற்றும் <strong>நைவேத்தியம்</strong> ஆகியவை ஒரு <strong>தட்டில்</strong> வைக்கப்படும். பெரிய பூஜைகளில் <strong>கலசம்</strong>, <strong>தேங்காய்</strong>, <strong>மாவிலைகள்</strong>, <strong>வெற்றிலை மற்றும் பாக்கு</strong>, <strong>மௌலி</strong> நூல், <strong>பஞ்சாமிர்தம்</strong> மற்றும் ஹோமத்திற்கு <strong>ஹோமப் பொருட்கள்</strong> சேர்க்கப்படும்.
</KeyTakeaway>

## அன்றாட அத்தியாவசியப் பொருட்கள்

| பொருள் | அது என்ன | பாரம்பரிய முக்கியத்துவம் |
| --- | --- | --- |
| **தியா** | நெய் அல்லது எண்ணெயில் பருத்தித் திரி வைத்து ஏற்றும் களிமண் அல்லது பித்தளை விளக்கு | இருளை அகற்றும் ஒளி; அதன் சுடர் பூஜைக்குச் சாட்சியாகக் கருதப்படுகிறது |
| **அகர்பத்தி / தூபம்** | ஊதுபத்திகள் அல்லது கூம்பு வடிவத் தூபம் | தெய்வத்துக்குச் சமர்ப்பிக்கப்படும் நறுமணம்; 5 அடிப்படைப் படையல்களில் ஒன்று |
| **தண்ணீர் (ஜலம்)** | சிறிய பாத்திரத்தில் (*லோட்டா*) வைக்கப்படும் சுத்தமான தண்ணீர் | தூய்மைப்படுத்துவதற்கும், உபசாரங்களில் கழுவுவதற்கும் அருந்துவதற்கும் அளிக்கப்படுகிறது |
| **குங்குமம் / ரோலி** | சிவப்புப் பொடி | மங்களத்தின் அடையாளம்; தெய்வத்துக்குப் பூசவும் திலகமாக இடவும் பயன்படுகிறது |
| **மஞ்சள்** | மஞ்சள் | தூய்மை மற்றும் மங்களம் |
| **சந்தனம்** | சந்தனப் பசை | குளிர்ச்சியும் நறுமணமும் தரும் காணிக்கை (*கந்தம்*) |
| **அட்சதை** | உடையாத முழு அரிசி, பெரும்பாலும் குங்குமம் கலந்து வைக்கப்படும் | முழுமை மற்றும் செழிப்பு |
| **மலர்கள்** | புதிய மலர்களும் மாலைகளும் | அழகும் பக்தியும்; குறிப்பிட்ட மலர்கள் குறிப்பிட்ட தெய்வங்களுடன் தொடர்புடையவை |
| **நைவேத்யம்** | பழங்கள், இனிப்புகள், பால் அல்லது சமைத்த உணவு | தெய்வத்துக்குப் படைக்கப்படும் உணவு, பின்னர் பிரசாதமாகப் பகிரப்படுகிறது |
| **மணி (கண்டி)** | சிறிய கைமணி | வழிபாட்டைத் தொடங்கும்போதும் ஆரத்தியின்போதும் ஒலிக்கப்படுகிறது |
| **தாலி** | பெரும்பாலும் பித்தளை அல்லது எஃகால் ஆன தட்டு | பூஜைப் பொருட்களை வைக்கவும் ஆரத்தி எடுக்கவும் பயன்படுகிறது |
| **கற்பூரம்** | வெள்ளை கற்பூர வில்லைகள் | ஆரத்தியின்போது ஏற்றப்படுகிறது; எச்சம் எதையும் விட்டுச் செல்லாமல் எரிவதால், அகந்தை கரைவதன் அடையாளமாகப் பலரும் இதைக் கருதுகிறார்கள் |

## பெரிய பூஜைகளுக்குத் தேவையான பொருட்கள்

| பொருள் | பாரம்பரிய முக்கியத்துவம் |
| --- | --- |
| **கலசம்** | நிறைவையும் தெய்வத்தின் இருப்பையும் குறிக்கும் நீர் நிரப்பிய பாத்திரம்; பல சடங்குகளில் முக்கிய இடம் பெறுகிறது |
| **மா இலைகள்** | கலசத்தின் வாயிலும் வாசல் தோரணத்திலும் வைக்கப்படுகின்றன; மங்களகரமானவை, புதிய தொடக்கங்களுடன் தொடர்புடையவை |
| **தேங்காய் (ஸ்ரீபலம்)** | தூய்மையான காணிக்கை; கலசத்தின் மீது வைக்கப்படுகிறது அல்லது காணிக்கையாக உடைக்கப்படுகிறது |
| **வெற்றிலை, பாக்கு (பான், சுபாரி)** | மரியாதையின் அடையாளமாக *தாம்பூலமாக* வழங்கப்படுகின்றன; சுபாரி சில சமயம் விநாயகராக வழிபடப்படுகிறது |
| **மௌலி / கலாவா** | பாதுகாப்புக்காகவும் நேர்த்திக்கடனின் அடையாளமாகவும் மணிக்கட்டிலும் கலசத்தைச் சுற்றியும் கட்டப்படும் சிவப்பு, மஞ்சள் நிறப் புனித நூல் |
| **பஞ்சாமிர்தம்** | பால், தயிர், நெய், தேன், சர்க்கரை ஆகியவற்றின் கலவை; தெய்வச் சிலைகளுக்கு அபிஷேகம் செய்யப் பயன்படுத்தப்பட்டு, பிரசாதமாகப் பகிரப்படுகிறது |
| **கங்காஜலம்** | கங்கையிலிருந்து கொண்டுவரப்படும் நீர்; பல வீடுகளில் தூய்மைப்படுத்தப் பயன்படுத்தப்படுகிறது |
| **ஜனேவு** | சில பூஜைகளில் தெய்வத்துக்குக் காணிக்கையாக அளிக்கப்படும் பூணூல் |
| **துணி (வஸ்திரம்)** | பொதுவாகச் சிவப்பு அல்லது மஞ்சள் நிறத்தில் இருக்கும் புதிய துணி; தெய்வத்துக்குக் காணிக்கையாக அளிக்கப்படுகிறது அல்லது பூஜை மேடையை மூடப் பயன்படுத்தப்படுகிறது |
| **துளசி இலைகள்** | விஷ்ணுவுக்கும் கிருஷ்ணருக்கும் படைக்கப்படுகின்றன; பாரம்பரியமாக விநாயகருக்குப் படைக்கப்படுவதில்லை |
| **வில்வ இலைகள்** | சிவனுக்குப் படைக்கப்படுகின்றன |
| **அருகம்புல்** | விநாயகருக்குப் படைக்கப்படுகிறது |
| **தட்சிணை** | பணமாக அளிக்கப்படும் காணிக்கை; பாரம்பரியமாகப் பூசாரிக்கு வழங்கப்படுகிறது |

## ஹவனத்திற்கு

ஹவனத்திற்கு (தீயில் செய்யப்படும் சடங்கு) தனியாகச் சில பொருட்கள் தேவை:

- **ஹவன குண்டம்**: தீ மூட்டப் பயன்படும், பெரும்பாலும் படிநிலைகள் கொண்ட செம்பு அல்லது இரும்புப் பாத்திரம்
- **சமித்து**: உலர்ந்த மரக்குச்சிகள், பொதுவாக மாமரக் குச்சிகள்
- **ஹவன சாமக்ரி**: மூலிகைகள், தானியங்கள், சர்க்கரை, மரப்பிசின்கள் ஆகியவற்றைக் கலந்து தயாரித்த பொருள்
- **நெய்**: கரண்டியால் தீயில் இடப்படுகிறது
- **நவதானியம்**: 9 கிரகங்களுடன் தொடர்புடைய 9 தானியங்கள், சில பூஜைகளில் பயன்படுத்தப்படுகின்றன

## வாங்குவதும் சேமித்து வைப்பதும்

- **பயன்படுத்தித் தீரும் பொருட்களைப் புதிதாக வாங்குங்கள்**: பூக்கள், பழங்கள், வெற்றிலைகளைப் பூஜை நாளுக்கு அருகில் வாங்குங்கள்.
- **பொடிகளைச் சரிபாருங்கள்**: அவற்றில் செயற்கை நிறங்கள் உள்ளனவா என்று பாருங்கள்; பல குடும்பங்கள் இயற்கையான குங்குமத்தையும் மஞ்சளையும் விரும்புகின்றன.
- **நீண்ட நாள் பயன்படும் பொருட்களை ஒன்றாக வைத்திருங்கள்**, பூஜை இடத்தில் சுத்தமாகவும் உலர்ந்தும் வைத்திருங்கள்; [பூஜை அறை வாஸ்து](/blog/pooja-room-vastu) பற்றிப் பாருங்கள்.
- **யார் எதை வழங்குவார்கள் என்று கேளுங்கள்.** பெரிய சடங்குகளுக்கு, பூஜைச் சாமக்ரியைப் பண்டிதர் கொண்டு வருவாரா அல்லது நீங்களே ஏற்பாடு செய்ய வேண்டுமா என்பதை உறுதிப்படுத்துங்கள்; [பூஜைக்கு பண்டிதரை முன்பதிவு செய்வது](/blog/how-to-book-pandit-for-puja-at-home) குறித்த எங்கள் வழிகாட்டியில் இதைப் பார்க்கலாம்.

## பூஜைக்குப் பிறகு

பயன்படுத்திய பூக்கள், இலைகள், அரிசி ஆகியவற்றைக் குப்பைத் தொட்டியில் வீசாமல் மரியாதையுடன் கையாள்வது வழக்கம். இப்போது பல குடும்பங்கள் அவற்றை ஆறுகளிலும் ஏரிகளிலும் போடுவதற்குப் பதிலாக **உரமாக்குகின்றனர் அல்லது தோட்டத்தில் புதைக்கின்றனர்**. இதனால் வழக்கத்தின் நோக்கம் காக்கப்படுவதோடு மாசுபாடும் தவிர்க்கப்படுகிறது. ஹோமத்தின் சாம்பலைப் பெரும்பாலும் தோட்டத்திலோ செடித் தொட்டியிலோ தூவுவார்கள்.

விரைவில் வரவிருக்கும் Aroha Puja-வில், ஒவ்வொரு முன்பதிவின்போதும் பூஜைக்குத் தேவையான அனைத்துப் பொருட்களையும் பண்டிதர் கொண்டு வருவதா, அல்லது பட்டியலின்படி உங்கள் குடும்பத்தினர் ஏற்பாடு செய்வதா என்பதை நீங்கள் தேர்வு செய்யலாம். உங்கள் தேர்வுக்கு ஏற்ப கட்டணம் அமையும்.
